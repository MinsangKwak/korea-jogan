영문 소문자·숫자·밑줄·하이픈으로 64자 이내 입력합니다. 영문 소문자나 숫자로 시작하세요. 예: 202611_readership / timeline_a

게시할 채널의 운영 규칙에 맞게 소개하세요. 추적 링크는 외부 소개에 사용하며, 신문 안의 메뉴·내부 링크에는 붙이지 않습니다. 게시 후 GA4의 캠페인·소스/매체에서 실제 유입을 비교할 수 있습니다.
