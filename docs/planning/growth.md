## 정치 질문 지면의 첫 4주

## 고정 도착 페이지

검색 결과나 공유 링크로 처음 방문해도 본문·제목·근거 링크를 읽을 수 있게 정적 HTML을 발행합니다. 각 페이지는 대표 주소(canonical)를 두고 사이트맵에 연결됩니다.

| 독자가 찾는 것 | 도착 주소 | 제공하는 내용 |
| --- | --- | --- |
| 오늘의 정치 질문·생활 정책·용어 | `/`, `/politics/`, `/politics/<질문 ID>/` | 당일 지면, 질문별 짧은 답·근거 원문·다음 확인 사항 |
| 사건이 어디까지 진행됐는지 | `/topics/`, `/topics/<사안 ID>/` | 사건별 연표, 마지막 변화, 다음 확인 사항과 관련 기사 |
| 특정 날짜의 보도·정정 | `/archive/`, `/YYYY-MM-DD` | 초안을 제외한 공개 호와 그날 기준의 기록 |
| 경제 지표의 값과 기준일 | `/indicators/`, `/indicators/<지표>/` | 지수·환율·유가·휘발유·금리의 수록 값, 기준일과 출처 |
| 지역 소식·매체별 수치 차이 | `/regions/<시도>/`, `/compare/<발행일>-<주제 ID>/` | 지역은 최근 14개 호까지, 비교 기록은 해당 날짜의 기사와 수치 |

2026년 11월 4일에는 공개 호 17개·추적 사안 2개·핵심 지표 6개로 검색 지면을 시작했습니다. 11월 16일에는 호별 지역 기사와 언론 주제를 각각 지역·날짜별로 다시 묶었습니다. 11월 20일에는 정치 질문을 추가하고 기존 재판 추적 주소를 그대로 사용했습니다. 날짜별 호는 발행 당시 기준을 유지합니다. [검색 지면 도입 기록](../dev/changelog.md#20261104-검색-도착-페이지와-유입-점검)

## 재방문 경로 (RSS·기록 페이지)

1면은 이 브라우저가 마지막으로 홈을 본 날짜(한국 시간)와 사건 변경일을 비교합니다. 지난 방문 뒤 바뀐 카드에만 표시를 붙이고 같은 탭에서 새로고침해도 유지합니다. 이슈별 읽기 이력은 저장하지 않습니다.

홈·지난 호·기록 페이지에서 ‘아침 받아보기’ 또는 ‘새 호 받아보기’를 열면 RSS 주소를 확인할 수 있습니다. 자바스크립트가 꺼져도 주소를 읽을 수 있고, 자동 복사가 제한되면 선택해 복사할 수 있습니다. 관리자는 안내 열기, 주소 복사 성공, RSS·이슈·지표 링크 클릭을 각각 셉니다. RSS 구독자 수는 이 이벤트로 알 수 없습니다. [RSS](https://korea-jogan.com/feed.xml)

- **제목과 날짜** — 11월 18일에는 날짜와 ‘오늘 뉴스 요약’을 제목에 넣었습니다. 11월 20일 이후에는 ‘오늘 정치 한 장’, 날짜, ‘광고 없는 뉴스 요약’을 함께 표시합니다. GA4에서 첫 화면을 비교할 때는 경로 `/`로 모읍니다.
- **새 호 발견** — `news-sitemap.xml`은 최근 이틀 안에 공개한 호를 담고 `robots.txt`에서 연결합니다. 새 호 배포 뒤 WebSub 허브에 RSS 갱신을 알립니다. 실제 색인은 Search Console에서 따로 확인합니다.

11월 17일 구현한 알림은 머리기사·첫 문단·주요 수치와 호 주소를 전송하도록 설계했습니다. 자동 발행 호에는 원문 확인 상태를 표시합니다. 이미 공개한 호는 재전송 대상에서 제외합니다. [전송 스크립트](../../dev/pipeline/publish/notify_telegram.py)

## Search Console에서 확인할 보고서

관리자의 ‘Google 검색 연결’에서 상위 검색어·페이지 각 10개, 세 질문의 검색 실적, 대표 URL의 색인 기록을 읽기 전용으로 조회합니다. 실적은 태평양 시간 기준 3일 전까지의 확정 자료에서 7일 또는 28일을 선택합니다. [연결 설정](../dev/ga4-admin.md#google-검색-연결)

1. 검색 유형은 **웹**으로 두고 같은 기간·기기 조건에서 전체 국가와 대한민국을 각각 확인합니다. 검색어와 페이지별 클릭·노출 건수를 먼저 보고 CTR과 평균 순위를 확인합니다.
2. 노출과 클릭이 함께 줄면 사이트맵의 발견 URL, 색인 제외 사유, Google이 선택한 대표 주소를 살핍니다. 노출이 비슷하면 제목·설명과 실제 검색 의도를 대조합니다.
3. 검색 클릭과 GA4 유입 추이가 다르면 기간, 호스트, 내부 접속 제외, 태그 차단과 수집 오류를 점검합니다. 방문 뒤 행동이 드물면 첫 답의 내용과 링크 위치를 검토합니다.

## 외부 소개

관리자의 ‘홍보 글과 추적 링크 만들기’에서 제목·핵심 세 줄·고정 주소를 복사합니다. 학자금 정책은 대학·취업 커뮤니티의 정보공유 게시판처럼 독자의 질문과 맞는 곳을 후보로 둡니다. 글에는 답을 먼저 적고 조건과 출처를 보려는 사람에게 질문 주소를 제공합니다. 복사와 실제 게시는 따로 기록합니다.

| 소개 위치 | 보여줄 사례 |
| --- | --- |
| 포트폴리오·GitHub | 직접 맡은 기획·구현·검사와 ‘편집자 확인’·‘자동 발행’을 나눈 이유 |
| 기술 글 | 수치 기준일 보존, 출처의 검증 범위, 반응형 설계 |
| 독자 커뮤니티 | 학자금 이자 면제 대상, 무안공항 참사 진행 경과, 환율 기준일처럼 글 하나에서 답할 구체적인 질문 |

게시 후 게시일·게시 URL·도착 URL·UTM·소개 사례를 남깁니다. 외부 링크에는 `utm_source`(게시처), `utm_medium`(social·email·referral), `utm_campaign`(기본 `YYYYMM_readership`), 필요 시 `utm_content`(사례·문구)를 붙입니다. 영문 소문자·숫자로 시작하고 소문자·숫자·밑줄·하이픈만 사용합니다. 내부 이동은 원래 주소를 유지합니다.

```text
https://korea-jogan.com/topics/muan-airport/?utm_source=portfolio&utm_medium=referral&utm_campaign=202611_readership
```

주제와 관계없는 게시판, 반복 게시, 링크 구매·교환은 운영 대상에서 제외합니다.
