# 검색·외부 소개·재방문 운영

**검색어에 맞는 고정 페이지를 두고, 노출 → 클릭 → 읽기 → 재방문의 변화를 같은 조건으로 확인합니다.** 일 1,000조회는 운영 목표이며 현재 성과나 달성 예측이 아닙니다. 방문자·세션·조회수는 서로 다른 지표로 기록하고, 구조 개선·색인 요청·외부 게시만으로 순위나 유입 증가를 주장하지 않습니다.

## 재방문 경로 (RSS·기록 페이지)

첫 화면·지난 호·주제·지표 페이지 상단의 `아침 받아보기`/`새 호 받아보기`가 RSS 안내(`https://korea-jogan.com/feed.xml`)를 열고, `이슈 진행 기록`·`경제 숫자와 기준일`이 기록 페이지로 이어집니다. 안내는 `reader_panel.py`가 모든 공개 페이지에 같은 내용으로 생성하며 자바스크립트 없이도 주소·링크가 보이고, 자동 복사가 제한되면 주소를 선택해 복사합니다. 이메일·알림 권한·회원가입은 없습니다.

| 관리자 행동 이름 | 측정 시점 |
| --- | --- |
| 받아보기 안내 열기 | RSS 안내를 펼쳤을 때 |
| RSS 주소 복사 / RSS 열기 | 복사 성공 / 직접 열기 링크 클릭 |
| 이슈 기록 열기 / 지표 기록 열기 | 안내의 링크 클릭 |

열기·복사 횟수는 구독자 수가 아닙니다. 내부 접속 제외 기준을 따르며 방문자를 행별로 더하지 않습니다.

## Search Console에서 확인할 보고서

검색 노출의 증감은 GA4 방문 그래프 대신 Search Console 검색 실적에서 봅니다. 관리자의 `Google 검색 연결`은 읽기 전용으로 검색어·페이지 상위 10개, 태평양 시간 기준 7일/28일 확정 자료(3일 전까지), 대표 주소의 색인 기록을 조회하며 색인 요청·설정 변경은 하지 않습니다([연결 설정](../dev/ga4-admin.md#google-검색-연결)).

1. 검색 유형 **웹**, 오늘을 뺀 완료된 7일과 직전 7일 비교.
2. 국가 **전체**와 **대한민국**을 각각, 기기는 같은 조건으로.
3. 클릭·노출·CTR·평균 게재순위를 검색어·페이지 표에서 절대값과 차이로. 브랜드명 검색과 주제 검색 구분.
4. 페이지 색인 보고서의 제외 사유, 첫 화면·호별·주제/지표 페이지 URL 검사, Google이 선택한 canonical.
5. 사이트맵 가져오기 상태와 발견 URL.

| 보고서 변화 | 다음에 확인할 점 |
| --- | --- |
| 노출·클릭 함께 감소 | 색인·크롤링·검색어 수요·페이지별 감소 범위 |
| 노출 비슷, 클릭 감소 | 제목·설명, 검색 의도와 본문 일치, CTR·순위 |
| 검색 클릭 비슷, GA4 유입 감소 | 날짜·호스트 조건, 측정 제외, 태그 차단·수집 오류 |
| 방문 증가, 읽기 행동 적음 | 도착 페이지 첫 설명, 기준일, 원문 접근 흐름 |
| 유입 뒤 재방문 적음 | GA4 첫 진입·참여 시간·첫 방문/재방문과 RSS 안내 행동 |

짧게 운영된 시기에는 적은 클릭 수의 백분율보다 실제 건수를 먼저 봅니다.

## 외부 소개

관리자 `홍보 글과 추적 링크 만들기`에서 제목·핵심 3줄·고정 주소를 복사합니다. 사이트 기능은 외부 게시를 대신하지 않으며 이미 제공하는 기능(진행 단계·날짜별 기록·근거 기사, 지표 기준일·출처, 지난 호·RSS)만 소개합니다. 실시간 시세·원문 확인 완료·방문자 증가 같은 미확인 성과는 넣지 않습니다.

| 주제 | 제목 | 도착 페이지 |
| --- | --- | --- |
| 진행 경과 | 무안공항 참사, 지금 어디까지 진행됐을까? | `/topics/muan-airport/` |
| 숫자 기준 | 환율 기사마다 숫자가 다르다면, 기준일을 확인해 보세요 | `/indicators/usd-krw/` |
| 전체 소개 | 핵심 숫자와 출처를 함께 보는 대한민국 조간 | `/` |

| 소개 위치 | 적을 내용 |
| --- | --- |
| GitHub README·저장소 소개 | 출처·기준일·정정과 자동 발행/사람 확인의 구분 |
| 포트폴리오·개발자 프로필 | 직접 맡은 기획·구현·검사와 읽기 흐름 |
| 기술 글 | 같은 지표의 기준이 달라지는 이유, 출처 보존·검사·반응형 설계 |
| 주제별 공유 글 | 현재 확인된 사실과 다음 확인 사항 |

UTM 규칙: `utm_source`(naver_cafe, threads, kakao, blog, newsletter, portfolio, technical_blog 등 게시처) · `utm_medium`(SNS social, 뉴스레터 email, 그 밖 referral) · `utm_campaign`(기본 `YYYYMM_readership`) · `utm_content`(timeline_a, exchange_a 등). 영문 소문자·숫자로 시작하고 소문자·숫자·밑줄·하이픈만 씁니다. 사이트 내부 탐색에는 붙이지 않습니다.

```text
https://korea-jogan.com/topics/muan-airport/?utm_source=portfolio&utm_medium=referral&utm_campaign=202611_readership
```

첫 실험은 주제 두 개·외부 채널 두 곳을 2주간 비교합니다. 게시 뒤 **게시일·게시 URL·도착 URL·UTM·소개한 사례**를 남기고 같은 기간의 GA4 캠페인·소스/매체·첫 진입 페이지와 Search Console을 함께 봅니다. 글 복사와 실제 게시, 링크 클릭과 구독 완료를 구분합니다. 링크 구매·교환 모임·자동 등록, 무관한 게시판에 주소만 남기기, 같은 글의 반복 게시는 하지 않습니다.
