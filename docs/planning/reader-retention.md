# 새 호와 기록을 다시 읽는 경로

**첫 화면과 기록 페이지에서 관련 기록·경제 기준일·새 호 RSS로 이동할 수 있습니다.** 기존 RSS 발행을 독자가 쉽게 찾도록 안내를 추가했습니다.

## 공개 화면

- 상단의 `아침 받아보기` 또는 `새 호 받아보기`를 누르면 RSS 안내가 열리고 해당 위치로 이동합니다.
- `이슈 진행 기록`과 `경제 숫자와 기준일`은 날짜별 기록을 계속 읽는 경로입니다.
- RSS 리더에 `https://korea-jogan.com/feed.xml`을 추가하면 새 호 발행을 확인할 수 있습니다.
- 자동 복사가 제한되면 주소를 선택해 직접 복사할 수 있습니다. 자바스크립트 없이도 주소와 RSS 링크가 보입니다.

이메일 발송·알림 권한·회원가입은 추가하지 않았습니다. RSS 리더에 주소를 등록하는 단계는 독자가 직접 진행합니다.

## 확인할 수 있는 행동

| 관리자 행동 이름 | 측정 시점 |
| --- | --- |
| 받아보기 안내 열기 | RSS 안내를 펼쳤을 때 |
| RSS 주소 복사 | 클립보드 복사에 성공했을 때 |
| RSS 열기 | RSS 직접 열기 링크를 눌렀을 때 |
| 이슈 기록 열기 | 안내의 이슈 기록 링크를 눌렀을 때 |
| 지표 기록 열기 | 안내의 경제 지표 링크를 눌렀을 때 |

기존 내부 접속 제외 기준을 따릅니다. 열기·복사 횟수는 구독자 수나 구독 완료 수가 아닙니다. 관리자에서 첫 방문·재방문 세션과 함께 추세를 확인하며 방문자를 행별로 더하지 않습니다.

## 검증

모바일 상단에서 안내 열기·키보드 포커스·복사 성공과 실패, 정적 페이지의 자바스크립트 없는 RSS 접근, 안내 중복 삽입 방지를 검사합니다. 공개 페이지 빌드가 오늘 호·지난 호·기록 페이지에 같은 안내를 생성합니다.
