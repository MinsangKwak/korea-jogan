**공개 사이트의 검색 접근 조건과 Google 계정에서만 확인할 수 있는 검색 실적을 분리해 확인합니다.** HTTP 응답이나 사이트맵 존재만으로 Google 색인 완료를 주장하지 않습니다.

## 공개 기술 점검

| 점검 | 결과 |
| --- | --- |
| 사이트맵 URL | 31개 |
| 페이지 HTTP 응답 | 31개 모두 200 |
| 자기 주소를 가리키는 canonical | 31개 모두 일치 |

오늘 호·지난 호·이슈 기록·지표 기록의 공개 접근 상태를 확인한 결과입니다. 소유권 확인 메타의 존재가 계정의 실제 권한이나 검색 엔진의 처리 완료를 보증하지는 않습니다.

## 관리자에서 실제 확인

[관리자](https://korea-jogan.com/admin/)의 `Google 검색 연결`에서 속성 조회 권한이 있는 계정으로 동의한 뒤 확인합니다. 연결 설정은 [운영 화면 안내](../dev/ga4-admin.md#google-검색-연결)를 따릅니다.

| 상황 | 다음 확인 |
| --- | --- |
| 검색 노출이 적음 | 대표 5개 주소의 Google 색인 기록과 사이트맵 제출 상태 |
| 노출은 있으나 클릭이 적음 | 해당 검색어와 페이지의 질문·제목·설명 일치 여부 |
| 유입 이후 재방문이 적음 | GA4 첫 진입·참여 시간·첫 방문/재방문과 RSS 안내 행동 |

Search Console 계정의 실제 노출·클릭·색인 결과는 이 문서를 작성할 때 조회하지 않았습니다. 계정 동의 이후의 실제 결과로 진단을 이어 가야 합니다.

## 기능의 범위

검색 읽기 전용 권한으로 검색 실적·사이트맵 등록 기록·Google 색인 버전을 조회합니다. 검색어·페이지는 상위 10개, 날짜는 태평양 시간 기준 7일/28일 확정 자료이며 3일 전까지 조회합니다. 색인 생성 요청이나 설정 변경은 수행하지 않습니다.

공식 기준: [검색 실적 API](https://developers.google.com/webmaster-tools/v1/searchanalytics/query), [색인 기록 API](https://developers.google.com/webmaster-tools/v1/urlInspection.index/inspect).
