# 주제별 소개와 유입 실험

관리자 화면의 **홍보 글과 추적 링크 만들기**에서 제목·핵심 3줄·해당 주제의 고정 주소를 함께 복사합니다. 사이트 기능은 외부 게시를 대신하지 않으며, 실제 게시한 글의 주소와 날짜를 기록해 성과를 비교합니다.

## 사용할 수 있는 소개

| 주제 | 제목 | 도착 페이지 |
| --- | --- | --- |
| 진행 경과 | 무안공항 참사, 지금 어디까지 진행됐을까? | `/topics/muan-airport/` |
| 숫자 기준 | 환율 기사마다 숫자가 다르다면, 기준일을 확인해 보세요 | `/indicators/usd-krw/` |
| 전체 소개 | 핵심 숫자와 출처를 함께 보는 대한민국 조간 | `/` |

현재 진행 단계·날짜별 기록·근거 기사, 지표별 기준일·출처, 지난 호·RSS 등 이미 제공하는 기능만 소개합니다. 실시간 시세·원문 확인 완료·방문자 증가 같은 확인되지 않은 성과를 넣지 않습니다.

## 링크 규칙

- `utm_source`: naver_cafe, threads, kakao, blog, newsletter 중 게시할 곳
- `utm_medium`: SNS는 social, 뉴스레터는 email, 그 밖은 referral
- `utm_campaign`: 같은 실험의 묶음. 기본은 한국 시간 기준 `YYYYMM_readership`
- `utm_content`: 주제·문구 구분. timeline_a, exchange_a, morning_a 등

캠페인과 글 구분은 영문 소문자·숫자로 시작하고 소문자·숫자·밑줄·하이픈을 사용합니다. 공개 가능한 분류 이름만 입력합니다. 사이트 내부 탐색에는 UTM을 붙이지 않습니다.

## 첫 실험

주제 두 개와 실제 운영할 외부 채널 두 곳을 정해 2주간 비교합니다. 동일 글을 무관한 게시판에 반복 게시하지 않고, 각 채널의 독자가 궁금해할 질문과 해당 근거를 소개합니다. 방문이 적으면 백분율보다 실제 세션·방문자·참여 시간을 먼저 확인합니다.

게시 후 게시일·실제 게시 URL·도착 URL·UTM을 남기고 같은 기간의 GA4 캠페인·소스/매체·첫 진입 페이지를 비교합니다. 글 복사와 실제 게시, 링크 클릭과 구독 완료를 구분합니다.
