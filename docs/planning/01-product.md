# 서비스 기획과 검증 계획

**대한민국 조간은 정치 뉴스가 낯선 독자가 질문 하나를 골라 답과 근거를 함께 읽는 광고 없는 신문입니다.** 곽민상은 개인 프로젝트에서 질문의 정보 구조, 신문·판례 간 이동, 발행 기준과 측정 방식을 설계했습니다. 예를 들어 ‘파기환송’ 해설을 읽은 독자는 같은 화면에서 실제 판결 주문을 확인하고 다음 재판을 맡을 법원을 골라볼 수 있습니다. [파기환송 해설과 판결문](https://korea-jogan.com/politics/reversal-and-remand/) · [통합 기획·편집 기준](https://app.notion.com/p/3decbbdd109b812e8a90f88de1c66a33)

## 해결하려는 문제

| 독자가 부딪히는 문제 | 제품에 반영한 결정 | 확인할 화면 |
| --- | --- | --- |
| 지난 보도를 보고 지금도 같은 상황인지 알기 어렵다 | 사건이 실제로 바뀐 날과 자료를 마지막으로 확인한 날을 따로 표시한다. 미정인 기일은 미정으로 둔다. | [재판 기일과 사건별 연표](https://korea-jogan.com/topics/lee-jae-myung-trials/) |
| 정책 안내에서 내게 영향을 주는 시점과 조건을 찾기 어렵다 | 질문 바로 아래에 한 줄 답을 두고 적용 대상, 공포일·시행일과 원문을 이어 읽게 한다. | [학자금대출 이자 면제](https://korea-jogan.com/politics/regional-student-loan-interest/) |
| 같은 지표를 다루는 기사의 수치가 서로 다르다 | 비교 기간과 집계 범위를 나란히 두고 결산·잠정·전망을 구별한다. 차이가 생긴 이유를 확인하지 못한 경우 그 범위를 적는다. | [매체별 수치 비교](https://korea-jogan.com/compare/) |

## 현재 제공하는 읽기 흐름

- **처음 온 독자**는 검색이나 공유 링크로 질문에 바로 들어옵니다. 답·확인일·근거 원문을 먼저 보고 용어 풀이, 판례, 다음 일정 중 필요한 정보를 고를 수 있습니다. [정치 질문 모음](https://korea-jogan.com/politics/)
- **다시 온 독자**는 1면의 ‘최근 달라진 이슈’에서 변경일을 확인합니다. 현재 이슈의 연표는 고정 주소에서 갱신하고, 지난 호에서는 당시 읽을 수 있던 내용만 제공합니다. [1면](https://korea-jogan.com/) · [지난 호](https://korea-jogan.com/archive/)
- **하루의 신문을 읽는 독자**는 1면부터 전국·이슈 추적·지역·언론·정치·경제·산업·재정 순으로 이동합니다. 지역면은 17개 시도를 6개 권역으로 묶고 산업면은 반도체 이외의 주력 품목도 비교합니다.

PC에서는 기사와 근거를 나란히 비교합니다. 모바일에서는 핵심 정보를 먼저 읽고 보조 자료를 펼칩니다. 이슈 추적 패널을 닫으면 열었던 버튼과 읽던 위치로 돌아갑니다. [반응형 배치와 키보드 조작](../../design/guide.md) · [브랜드 자산](../../design/illustrations.md)

### 기사에서 판례로 이어지는 읽기 흐름

1. **기사와 선례를 연결합니다.** 1면에 같은 법적 쟁점을 다룬 기사와 대법원 선례를 싣습니다. 발행일과 선고일, 두 사건을 연결한 이유를 표시합니다. 새 연결이 없는 호는 기존 쟁점의 원래 날짜를 유지하고, 연결 사례가 없는 지난 호는 검색을 제공합니다. [선정 사례와 근거](news-case-pairs.md)
2. **원하는 사건을 직접 엽니다.** ‘전세보증금 반환’ 같은 생활어 또는 사건번호로 검색하면 법원·선고일·판시사항과 원문 링크가 보입니다. 보관함에서는 두 판례를 나란히 볼 수 있습니다. [전세보증금 사례](https://korea-jogan.com/law/?issue=rental-deposit)
3. **법이 바뀌는 날짜를 확인합니다.** 입법 캘린더는 한국 시간 기준 이번 달부터 열립니다. 2025년 1월 이후 법률안 제안·법률 공포·시행과 앞으로 시행될 법률, 다음 관보 예고를 구분합니다. 날짜별 건수는 수록 자료 기준입니다. [입법 캘린더](https://korea-jogan.com/law/calendar/) · [집계 범위](law-data.md)

## 먼저 검증할 독자와 행동

첫 4주에는 **외부 방문자 100명**을 목표로, 세 질문에 대한 검색 노출과 답을 읽은 뒤의 행동을 관찰합니다. 개편 전에는 경제 수치를 보고서에 다시 쓰는 30~50대 직장인을 우선 독자로 가정했습니다. 지금은 독자가 해결하려는 질문을 기준으로 살핍니다. 실제 독자층과 사용 효과를 판단하려면 운영 데이터가 필요합니다. [첫 4주 검증 계획](growth.md#정치-질문-지면의-첫-4주)

### 측정할 수 있는 것과 해석의 한계

| 확인할 질문 | 관찰할 행동 | 해석할 때 볼 점 |
| --- | --- | --- |
| 어느 질문이 새 독자에게 닿는가? | 세 질문의 검색 노출·클릭, 외부 소개 글을 통한 방문 | 기간·국가·도착 페이지를 맞추고 검색과 외부 소개를 구분 |
| 답을 읽은 뒤 근거를 확인하는가? | 근거 원문·용어·캘린더 클릭, 신문에서 판례면으로 이동(`reader_law_open`) | 한 사람이 여러 번 클릭할 수 있음. 사건 검색어·상황문·보관 목록은 분석에서 제외 |
| 수치 비교와 출처 확인이 쓰이는가? | 비교 열기(`split-home`, `split-open`)와 출처 펼치기(`src-open`) | 펼치기는 외부 원문 방문과 별개. 방문 100회당 행동 수는 반복을 포함해 100을 넘을 수 있음 |
| 읽기나 탐색이 어디서 끊기는가? | 주제 검색·결과 없음, 지면 이동(`section_<id>`)·체류(`dwell_<id>`) | 검색어 원문을 전송하지 않음. 머문 시간만으로 이해도를 판단하기 어려움 |

GA4 이벤트 이름에서는 하이픈을 밑줄로 바꿉니다. 내부 표시 브라우저와 자동화 브라우저를 제외합니다. 정정은 신고·정정 날짜를, 정시 발행은 실제 공개 기록을 대조합니다. [측정 코드](../../dev/web/src/core/metrics.js) · [관리자 연결·지표 정의](../dev/ga4-admin.md)

## 확인 수준과 운영 책임

자료에는 발행일, 통계 기준일, 수집 시각과 원문 확인 범위를 남깁니다. 확정 통계(A), 잠정 통계(B), 정책 발표(C), 언론·민간 집계(D), 분석·계산(E)을 구별합니다. 조사 종료일이 미정인 이슈는 마지막으로 확인한 단계와 남은 일만 표시합니다. [데이터 규격](data-spec.md)

### 호의 상태와 확인 주체

| 상태 | 독자에게 보이는 상태 | 공개 기준 |
| --- | --- | --- |
| `draft` | 공개 전 | 조사와 편집을 마친 초안으로 검사 후 발행 대기 |
| `published` + 사람의 `review.by` | 편집자 확인 | 운영자가 머리기사·핵심 수치·매체별 수치 차이를 원문과 대조하고 승인 |
| `published` + `review.auto` | 자동 발행 | 06시 발행 시점까지 사람 확인이 없는 호를 자동 검사한 뒤 공개 |
| `prototype` | 시안 | 운영자가 수동 작성하며 공개 호 검증과 별도로 관리 |

두 공개 경로 모두 데이터 검사를 거칩니다. 일일 발행은 안정 브랜치에서 해당 호의 데이터만 선별합니다. 공개 후 오류를 확인하면 호를 수정하고 정정일·이전 값·새 값·사유를 기록합니다. [운영 런북](runbook.md) · [배포 절차](../dev/branches.md) · [날짜별 변경 기록](../dev/changelog.md)

### 하지 않는 것

장중 시세 중계, 정당 공방·인물 평가, 기사 전문 저장, 회원제·댓글·광고는 서비스 범위 밖입니다. 기사 제목·출처 링크와 직접 작성한 요약을 보관합니다.

## 후속 과제

첫 2주에는 실제 검색어와 독자가 남긴 질문을 살피고, 4주에는 어떤 주제를 더 편집할지 결정합니다. 원문 열람이 드물면 답의 첫 문장과 출처 링크 배치를 검토합니다.

자료 확장 후보는 KOSIS·관세청 수집 확대, 2026년 9월 24일 이후 정부·위원장 제안 법률안 보완, 월·연 단위 아카이브입니다. [법률 자료 범위](law-data.md) · [유입 실험과 판정 기준](growth.md)
