# 검색 유입과 외부 소개 운영 계획

**검색어에 맞는 고정 페이지를 만들고, 노출 → 클릭 → 읽기 → 재방문의 변화를 확인합니다.** 일 1,000조회는 운영 목표이며 현재 성과나 달성 예측이 아닙니다. 방문자·세션·조회수는 서로 다른 지표로 기록합니다.

## 먼저 확인할 현재 상황

2026.11.04 사용자가 공유한 캡처에서 방문 감소가 보입니다. 다만 아래 두 화면은 **기간과 조회 조건이 다른 자료**이므로 하나의 시계열로 합치지 않습니다. 이번 문서 편집에서 GA4·Search Console 원본 보고서에 로그인하거나 재조회하지 않았습니다.

| 공유된 화면 | 확인되는 수치 | 판단 범위 |
| --- | --- | --- |
| 관리자 · 최근 28일 | 방문자 121명, 조회수 126회, 세션 131회, 평균 참여 시간 4초. 채널별 세션 Direct 127·Organic Search 2·Referral 2 | 검색 유입의 절대 규모가 작고 출처 미확인 유입 비중이 큼 |
| 관리자 · 오늘 포함 최근 7일 | 방문자 26명, 조회수 27회, 평균 참여 시간 8초 | 오늘의 집계 지연과 조회 범위를 함께 확인해야 함 |
| GA4 홈 · 지난 7일 | Direct 37세션(-60.2%), Organic Search 0세션(-100%), Referral 2세션 | 검색 노출 감소율을 뜻하지 않음. 비교 대상 7일의 Organic 절대값은 이 화면에 표시되지 않음 |

Direct는 명확한 추천 출처가 없는 유입입니다. 전체를 주소 직접 입력이나 봇으로 분류하지 않습니다. 해외 지역·짧은 체류만으로 봇이라고 판정하지 않습니다.

**2026.10.30부터 측정 기준이 바뀌었습니다.** 자동화 브라우저와 운영자 표시 브라우저의 방문을 제외합니다. 변경 전에는 배포 검증·운영 접속이 섞였을 가능성이 있으므로 전후 합계를 실제 독자 이탈률로 바로 읽지 않습니다. 관리자를 연 브라우저도 내부 방문으로 표시됩니다. [구현과 적용 시점](../dev/ga4-admin.md#체류-시간과-읽기-이벤트-해석)

## 실행 순서

| 순서 | 작업 | 완료 판단에 필요한 기록 |
| --- | --- | --- |
| 1 | 같은 조건으로 검색·방문 기준선 확보 | 오늘을 뺀 완료된 7일과 직전 7일, 국가·호스트·채널 조건 |
| 2 | 고정 도착 페이지의 접근·검색 수집 조건 확인 | HTTP 상태, 본문·제목·canonical, 사이트맵, URL 검사 결과 |
| 3 | 대표 사례를 외부에 소개 | 실제 게시 URL·게시일·UTM·연결한 고정 페이지 |
| 4 | 검색어와 도착 페이지별 반응 비교 | 노출·클릭·CTR·평균 게재순위, 읽기·원문 이동·재방문 |
| 5 | 반응이 있는 주제의 설명과 내부 연결 개선 | 바뀐 문장·주소, 같은 조건의 후속 보고서 |

먼저 10/30 이후 같은 기준으로 측정된 기간을 확보합니다. 서로 다른 측정 기준이 섞인 7일 비교에는 변경 사실을 남기며, 아직 완료되지 않은 오늘의 값을 이전 하루 전체와 비교하지 않습니다.

## 검색어에 맞는 도착 페이지

최신 첫 화면만 바뀌는 구조에서 벗어나, 같은 주제의 자료를 고정 주소로 다시 찾도록 정리합니다. 2026.11.04 작업의 초기 근거는 **공개된 17개 호, 기존 추적 사안 2개, 핵심 지표 6개**입니다. 기존 자료를 재구성한 페이지이며 새 취재 기사나 더 긴 공식 시계열이 아닙니다. 반영·검증 상태는 [변경 기록](../dev/changes-2026-11-04-seo.md)에서 확인합니다.

| 도착 페이지 | 독자가 찾을 내용 | 외부 소개에 쓸 때 |
| --- | --- | --- |
| `/` | 오늘의 전국 뉴스·공식 숫자·추적 사안 | 서비스 전체 소개 |
| `/archive/`, `/YYYY-MM-DD` | 날짜별 공개 호와 당시 기준 자료 | 특정 날짜의 비교·정정 사례 |
| `/topics/`, `/topics/<사안 ID>/` | 선관위 특검·무안공항 참사의 현재 기록, 단계·다음 확인·관련 기사 | 사안의 경과를 계속 확인하는 안내 |
| `/indicators/`, `/indicators/<지표>/` | 코스피·코스닥·원달러 환율·두바이유·휘발유·기준금리의 호별 기록 | 지표의 기준일·출처 차이를 설명하는 사례 |

지표의 호 발행일과 원자료 기준일을 구분합니다. 거래가 없거나 새 발표가 없는 날에는 같은 값이 여러 호에 실릴 수 있습니다. 이를 매일 새 관측값이나 당일 실시간 시세로 표현하지 않습니다. 출처 접근 여부·사람 확인·자동 발행을 혼동하는 설명도 추가하지 않습니다.

페이지에는 읽을 수 있는 정적 본문·고유 제목·설명·canonical·내부 링크를 두고 사이트맵에 연결합니다. 색인 요청이나 기술 조건 충족만으로 검색 게재·순위가 보장되지는 않습니다.

## Search Console에서 확인할 보고서

**검색 노출의 증감은 GA4 방문 그래프 대신 Search Console 검색 실적에서 확인합니다.** 아래 결과를 내보내거나 캡처할 때 조회일과 필터를 함께 남깁니다.

1. 검색 실적에서 검색 유형을 **웹**으로 맞추고, 오늘을 뺀 **완료된 최근 7일과 직전 7일**을 비교합니다. 최신 값이 미완성이라면 확정된 날짜까지의 같은 길이로 맞춥니다.
2. 국가 **전체**와 **대한민국**을 각각 확인합니다. 기기는 같은 조건으로 비교하고 필요하면 모바일을 따로 봅니다.
3. 클릭·노출·CTR·평균 게재순위를 켜고, **검색어**와 **페이지** 표에서 절대값과 차이를 확인합니다. 브랜드명 검색과 일반 주제 검색을 구분합니다.
4. 페이지 색인 보고서에서 색인된 페이지·제외 사유를 보고, 첫 화면·호별 페이지·새 주제/지표 페이지를 URL 검사합니다. Google이 선택한 canonical과 실제 정적 본문도 확인합니다.
5. 사이트맵의 가져오기 상태와 발견 URL을 확인합니다. 보안 문제·직접 조치가 표시되면 해당 보고서의 실제 사유부터 확인합니다.

| 보고서 변화 | 다음에 확인할 점 |
| --- | --- |
| 노출·클릭이 함께 감소 | 색인·크롤링·검색어 수요·페이지별 감소 범위 |
| 노출은 비슷한데 클릭 감소 | 제목·설명, 검색 의도와 본문의 일치, CTR·순위 변화 |
| 검색 클릭은 비슷한데 GA4 유입 감소 | 날짜·호스트 조건, 측정 제외, 태그 차단·수집 오류 |
| 클릭·방문은 늘었는데 읽기 행동이 적음 | 도착 페이지의 첫 설명, 정보의 기준일, 본문·원문 접근 흐름 |

이 구분은 조사 순서이며 자동으로 원인을 판정하는 규칙은 아닙니다. 서비스가 짧게 운영된 시기에는 적은 클릭 수의 백분율 변화보다 실제 건수를 먼저 봅니다.

## 외부 소개와 콘텐츠 운영

주소만 반복 게시하지 않고, 이 서비스가 직접 보여 줄 수 있는 비교 사례를 소개합니다. 외부 글 게시·프로필 수정·Notion 공개·메시지 발송은 이 문서 작업에서 수행하지 않았습니다.

| 소개 위치 | 적을 내용 | 연결할 곳 |
| --- | --- | --- |
| GitHub README·저장소 소개 | 출처·기준일·정정과 자동 발행/사람 확인의 구분 | 서비스·기술 문서 |
| 공개 포트폴리오·개발자 프로필 | 직접 맡은 기획·구현·검사와 읽기 흐름 | 서비스·대표 사례 |
| 기술 글 | 같은 지표의 기준이 달라지는 이유, 출처 보존·검사·반응형 설계 | 관련 고정 페이지·코드 |
| 주제에 맞는 공유 글 | 현재 확인된 사실과 다음 확인 사항을 짧게 설명 | 해당 사안 페이지·근거가 있는 호 |

외부에서 유입된 소개의 성과는 UTM으로 구분합니다. 예시는 실제 게시 전에 매체·문맥에 맞게 정하며, 사이트 안의 메뉴·내부 링크에는 UTM을 붙이지 않습니다.

```text
https://korea-jogan.com/topics/muan-airport/?utm_source=portfolio&utm_medium=referral&utm_campaign=202611_readership
https://korea-jogan.com/archive/?utm_source=technical_blog&utm_medium=referral&utm_campaign=202611_readership
```

게시 기록은 **게시일·게시 URL·도착 URL·UTM·소개한 사례**를 남깁니다. Search Console 노출·클릭과 GA4 유입/읽기 행동을 같은 기간으로 다시 확인합니다. 일 1,000조회 목표에 고정된 달성 기한이나 성장률을 약속하지 않습니다.
