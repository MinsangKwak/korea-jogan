# 외부 링크 늘리기

korea-jogan.com을 가리키는 바깥 사이트의 링크를 외부 링크로 부릅니다. 검색 엔진이 사이트를 얼마나 신뢰할지 판단하는 근거이며, 지금 이 사이트에 가장 모자란 항목입니다.

## 지금 상태

Search Console 링크 보고서(2026-11-02 확인) 기준입니다.

| 항목 | 값 |
| --- | --- |
| 외부 링크를 건 사이트 | 2곳, 둘 다 `github.com` |
| 그 밖의 사이트 | 없음 |

최근 3개월 실적은 노출 503회, 클릭 3회입니다. 이 가운데 한국에서의 노출은 23회(4.6%)이고 클릭 3회가 모두 여기서 나왔습니다. 미국에서 360회가 노출되었으나 클릭은 없습니다. 한국 독자에게 보이는 횟수 자체가 적은 것이 문제이고, 외부 링크가 거의 없는 것이 그 원인 가운데 하나입니다.

## 왜 외부 링크가 필요한가

- 검색 엔진은 새 사이트를 찾을 때 이미 아는 사이트의 링크를 따라갑니다. 링크가 없으면 사이트맵만으로 발견되며 순위 판단 근거가 부족합니다.
- `github.com` 두 건은 저장소 페이지에서 나온 것으로, 뉴스나 데이터 분야와 주제가 맞지 않습니다. 주제가 가까운 곳의 링크가 한 건이라도 생기는 쪽이 낫습니다.
- 링크를 사고팔거나, 관계 없는 게시판에 주소만 뿌리는 방식은 쓰지 않습니다. 검색 엔진의 제재 대상이고 포트폴리오로서도 설명이 되지 않습니다.

## 할 일

### 1. Notion 포트폴리오 공개 — 가장 먼저

Notion 포트폴리오 페이지가 비공개여서 링크가 집계되지 않습니다. 두 가지를 모두 켜야 합니다.

1. 페이지 오른쪽 위 **공유 → 웹에 게시**
2. 같은 패널의 **검색 엔진 인덱싱** 켜기

2번을 끄면 Notion이 페이지에 `noindex`를 붙입니다. 그러면 구글이 그 페이지를 색인하지 않고, 거기 걸린 링크도 외부 링크로 세지 않습니다. 공개만 해 놓고 멈추면 아무 효과가 없습니다.

공개한 뒤 페이지 안에서 확인할 것은 다음 세 가지입니다.

- 링크가 `https://korea-jogan.com/`으로 걸려 있는지. 단축 주소나 리디렉션을 거치면 전달이 약해집니다.
- 링크 글자가 주소 그대로가 아니라 사이트 이름인지. `대한민국 조간`처럼 적습니다.
- 사이트가 무엇을 하는 곳인지 두세 문장으로 적혀 있는지. 주변 글의 주제도 판단 근거가 됩니다.

### 2. 주제가 맞는 곳 한두 군데

한 건씩이라도 주제가 가까운 곳에 쌓습니다. 각 글은 사이트 소개가 아니라 만든 과정이나 결과물에 관한 글이어야 합니다.

| 곳 | 적을 내용 | 링크 위치 |
| --- | --- | --- |
| 개인 블로그·기술 글 플랫폼 | 매일 06:00에 자동으로 조간을 만드는 파이프라인을 어떻게 짰는지 | 글 본문에서 실제 화면을 가리킬 때 |
| GitHub 저장소 README | 지금도 있음. 주소가 맨 위에 보이는지만 확인 | 저장소 설명과 README 첫 단락 |
| 개발자 프로필(링크 모음) | 한 줄 소개와 주소 | 프로필 링크 칸 |

### 3. 사이트 쪽에서 받을 준비

링크를 받아도 도착한 페이지가 부실하면 효과가 줄어듭니다. 이미 되어 있는 것과 확인할 것을 나눕니다.

- 되어 있음: `robots.txt`, `sitemap.xml`, 호별 주소 `/YYYY-MM-DD`, 정규 주소(canonical), JSON-LD, `favicon.ico`, 옛 `?d=` 주소를 호별 주소로 옮기는 처리
- 확인할 것: 외부에서 들어온 주소가 어느 호를 가리키든 그 호가 그대로 보이는지. 링크를 걸 때는 최신 호가 바뀌어도 내용이 유지되는 호별 주소를 씁니다. 사이트 전체를 소개할 때만 `https://korea-jogan.com/`을 씁니다.

## 확인 방법

Search Console의 **링크 → 외부 링크 → 연결된 사이트 상위**에서 셉니다. 반영에는 시간이 걸립니다.

| 시점 | 기대 |
| --- | --- |
| 공개 후 2~7일 | 구글이 Notion 페이지를 색인 |
| 공개 후 2~4주 | 연결된 사이트 수가 2에서 3 이상으로 바뀜 |
| 공개 후 4~8주 | 한국 노출 비중이 4.6%에서 올라가는지 |

연결된 사이트 수가 4주가 지나도 그대로면 Notion 페이지가 색인되었는지부터 봅니다. 구글에서 `site:` 뒤에 그 Notion 주소를 붙여 검색하면 색인 여부를 알 수 있고, 안 나오면 **검색 엔진 인덱싱** 토글이 꺼져 있을 가능성이 가장 높습니다.

## 하지 않는 것

- 링크 구매, 링크 교환 모임, 자동 등록 서비스
- 주제와 무관한 게시판·댓글에 주소만 남기는 일
- 같은 글을 여러 사이트에 그대로 복사해 올리는 일

세 가지 모두 검색 엔진이 걸러내며, 적발되면 사이트 전체의 평가가 내려갑니다. 사이트를 1인 운영 데이터 저널리즘 결과물로 보여 주는 것이 목적이므로, 만든 과정을 설명하는 글에서 자연스럽게 링크되는 방식만 씁니다.
