# 기사와 판례를 함께 읽는 편집 기준

한 편의 기사에서 독자가 궁금해할 질문을 고르고, 같은 쟁점을 다룬 대법원 판결이나 결정을 연결한다. 기사의 사실관계·재판 단계와 선례의 결론을 구분한다. 조사 중인 사건은 조사 중이라고 쓰고, 과거 판결로 그 사건의 책임이나 결과를 단정하지 않는다.

## 추가·정정

[편집 목록](../../dev/web/data/news-case-pairs.json)에 원본 기사가 있는 호와 지면, 기사 제목·주소, 편집 질문, 연결 근거를 기록한다. 같은 분야의 [판례 색인](../../dev/web/law/data)에서 사건명·사건번호·선고일·일련번호를 대조한다. 기사와 선례를 연결할 분명한 질문이 있을 때만 추가하고 발행일 내림차순으로 정렬한다. 이미 게재한 항목을 정정할 때는 기존 식별자를 유지한다.

자료를 수정한 뒤 `python3 -m unittest discover -s dev/tests -p test_news_case_pairs.py`로 공개 호의 제목·기사 주소와 분야별 판례 원자료의 일치를 검사한다. 연결 근거의 타당성은 기사 정정이나 판결 변경이 있을 때 편집자가 원문과 함께 다시 검토한다.
