# 01 서비스 기획

**정확한 수치 없이 표현만 앞세우는 기사 대신, 공식 숫자와 그 출처·기준을 나란히 보여 주는 아침 신문을 만들었습니다.** 판단은 독자에게 맡기고, 서비스는 숫자가 어디서 왔고 무엇을 기준으로 했는지만 분명히 합니다.

## 문제

| 관찰한 문제 | 2026-10-19호 조사에서 확인한 예시 |
| --- | --- |
| 수치 없이 표현만 있는 기사 | 얼마나, 무엇과 비교해 바뀌었는지 없이 강한 표현만 앞세운 제목 |
| 같은 사실, 다른 숫자 | 지난주 코스피 하락률이 기사마다 14.46%와 11.21%. 계산은 둘 다 맞고 출발점만 다름 |
| 기간을 밝히지 않은 숫자 | 외국인 순매도가 3.6조에서 30.6조 원까지. 집계 기간과 대상이 서로 다름 |
| 이름이 비슷한 다른 지표 | 중앙정부 채무 1,372.1조를 '국가채무'라고 쓴 기사. 공식 국가채무는 중앙+지방 |
| 기간을 겹쳐 센 계산 | 국민연금 '182조 손실'과 '181조 감소'를 더한 '240조 증발'. 서로 다른 기준을 합친 숫자 |
| 관심이 한 주제에 쏠림 | AI 반도체 기사에 묻혀 철강·조선·자동차·석유화학·에너지 같은 주력산업 소식이 잘 보이지 않음 |
| 수도권 중심 | 17개 시도 소식을 한곳에서 보기 어려움 |

## 독자

20대부터 70대까지를 대상으로 합니다. 아침에 휴대폰으로 한 번 훑어보는 상황을 기준으로 정했습니다.

- 문장은 `~했습니다`체로, 결론을 먼저 1~2문장에 씁니다.
- 기준 글자 크기를 키우는 '가 글자 크게' 단추를 두고 선택을 기기에 저장합니다.
- 긴 목록은 접어 두고, 모바일에서는 하단 메뉴로 섹션을 바로 옮겨 갑니다. 섹션이 여덟 개라, 오른쪽 전체 메뉴에서 섹션 안의 항목(언론 주제·전국 분야·시도)까지 한 번에 고를 수 있게 했습니다.

### 1차 독자 가설 (확정 필요)

"20~70대 전체"로는 섹션 우선순위를 정할 수 없어, 먼저 검증할 독자를 하나로 좁힙니다. 글자 크기·하단 메뉴 같은 넓은 연령대 배려는 그대로 둡니다.

| 항목 | 가설 |
| --- | --- |
| 누구 | 경제 기사를 매일 읽고, 그 숫자를 투자 판단이나 업무 보고에 다시 쓰는 30~50대 직장인·개인 투자자 |
| 겪는 문제 | 기사마다 숫자가 달라 어느 것을 믿고 인용할지 판단하는 데 시간이 든다 |
| 이 서비스에서 할 일 | 홈의 '기준이 갈린 숫자'를 열어 보고, 출처를 펼쳐 원문으로 간다 |
| 틀렸다고 볼 신호 | 갈린 숫자·출처를 여는 비율이 낮고, 방문이 전국·지역 뉴스 목록에만 몰린다 |

## 성공 지표

측정은 [GoatCounter](https://www.goatcounter.com/)로 합니다. 쿠키를 쓰지 않고 개인을 식별하지 않습니다. `public/index.html`의 `<meta name="jg-goatcounter">`에 주소를 넣으면 켜지고, 비워 두면 아무것도 보내지 않습니다. 검색어 원문은 보내지 않고 걸린 주제 이름만 셉니다.

| 구분 | 지표 | 어떻게 재나 |
| --- | --- | --- |
| 북극성 | 방문 100회당 확인 행동 수 | (`split-home` + `split-open` + `src-open`) ÷ 방문 × 100 |
| 보조 | 갈린 숫자를 연 방문 비율 | `split-home`·`split-open` 이벤트 ÷ 방문 |
| 보조 | 출처를 펼친 횟수 | `src-open` 이벤트(기관 이름별) |
| 보조 | 찾는 주제와 실패한 검색 | `search` 이벤트. '결과 없음'이 많으면 주제 선정을 바꿉니다 |
| 신뢰 | 오류 신고 수와 정정까지 걸린 날 | GitHub '정정 요청' 이슈, `corrections.json` |
| 운영 | 제때 발행하지 못한 날 수 | `index.json` 발행 목록과 날짜 비교 |

재방문율은 개인을 구분해야 잴 수 있어 지금은 재지 않습니다. RSS 구독 수로 대신 가늠합니다.

## 섹션과 넣은 이유

| 섹션 | 넣은 이유 |
| --- | --- |
| 홈 | 바쁜 독자가 머리기사 하나와 숫자 3개, 그리고 오늘 기준이 갈린 숫자만 보고도 오늘을 파악하게 하려고 |
| 전국 | 하루의 큰 흐름을 분야별(사회·사건·날씨·안보·국제·과학·생활·문화)로 고르게 보여 주려고 |
| 지역 | 17개 시도를 권역(수도권·강원·충청·호남·영남·제주)으로 묶어 고르게 하고, 지역 언론 기사를 우선해 수도권 쏠림을 줄이려고 |
| 정치 | 정쟁 대신 경제 성장·국가 안보·국방과 법정 일정(임기·선거·예산 처리기한)에 집중하려고 |
| 경제 | 증시·환율·유가를 출처·기준일·신뢰도 등급과 함께 보여 주려고 |
| 산업 | 반도체 밖의 주력산업과 수출입을 상시로 보여 주려고 |
| 재정 | 국가채무가 해마다 얼마나 늘었는지, 국민연금이 어디에 투자되는지를 늘 확인할 수 있게 하려고 |
| 언론 | 한 주제를 언론사들이 어떻게 다르게 썼는지 보여 주려고. 위에는 AI 요약과 기준이 갈린 숫자, 아래에는 기사 링크만 둡니다 |

## 넣지 않은 것

| 뺀 것 | 이유 |
| --- | --- |
| 정당 공방, 인물 평가 | 비영리·중립 운영. 사실과 일정만 다룹니다 |
| 지표의 좋고 나쁨 평가 | 상승·보합·하락 방향만 표시하고 해석은 독자에게 맡깁니다 |
| 기사 본문 저장 | 저작권. 제목·직접 쓴 짧은 요약·링크만 둡니다 |
| 회원·댓글·광고 | 1인 비영리 운영에서 관리 비용과 개인정보 부담이 크기 때문입니다 |
| 출처 없는 숫자 | 검사 스크립트가 막습니다. 확인하지 못한 값은 빼거나 '미확인'으로 적습니다 |

## 신뢰를 보여 주는 장치

- **출처 신뢰도 등급**: A 공식 확정 통계 · B 공식 잠정 통계 · C 공식 정책 발표 · D 언론 보도·민간 집계 · E 분석·계산.
- **결산과 전망 구분**: 국가채무 막대는 결산과 전망을 다른 모양으로 그리고, 금액을 확인하지 못한 해는 막대 대신 '미확인'으로 표시합니다.
- **법정일과 계산일 구분**: 선거·예산 D-Day마다 '헌법 제54조', '현행법 기준 예상'처럼 근거를 붙입니다.
- **한계 공개**: 접속이 막혀 다른 매체로 대체한 사실, 해외 기사가 부족해 날짜 범위를 넓힌 사실을 화면 하단에 적습니다.

## 운영 방식

혼자 운영합니다. Claude 예약 작업이 00시에 조사·작성·검사까지 해서 초안(`draft`)을 남기고, 검사를 통과하지 못하면 초안도 올리지 않습니다. 배포는 사람이 머리기사·핵심 숫자·갈린 숫자를 원문과 대조해 승인한 뒤에만 합니다. 조사는 기계에게, 책임은 사람에게 두는 구조입니다. 자세한 흐름은 [02 구조와 자동화](02-architecture.md)에 있습니다.
