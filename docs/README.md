## 조사 근거 읽기

[무안공항 참사 조사 기록](research/muan-airport-20261030.md)은 2026.10.30에 확인한 자료의 범위를 보존합니다. 현재 사안별 기사·단계는 [trackers.json](../dev/web/data/trackers.json)을 확인합니다. 과거 조사 문서를 현재의 공식 최종 판단으로 읽지 않도록 시점을 구분합니다.

원문 접근 여부·사람의 대조·AI 형식 검사는 서로 다릅니다. 데이터 검사 통과와 실제 이용자 성과도 구분해서 기록합니다.
