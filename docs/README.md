## 문서 작성 규칙

- 결론을 먼저 씁니다. 같은 설명을 여러 문서에 반복하지 않고 링크로 잇습니다.
- 코드·데이터에 없는 내용은 쓰지 않습니다. 계획은 '예정'·'준비 중'으로 구분합니다.
- 비밀값(API 키, 접속 정보)은 문서에 넣지 않습니다.
