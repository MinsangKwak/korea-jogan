# Claude 작업 지침

## 언어

- 사용자에게 하는 모든 말은 **한국어로만** 씁니다. 답변, 진행 상황 안내, 질문, 요약을 모두 포함합니다.
- PR 제목·본문, 커밋 메시지, 이슈·리뷰 댓글, 문서도 한국어로 씁니다. 커밋 제목 규칙은 [docs/guides/COMMITS.md](guides/COMMITS.md)를 따릅니다.
- 코드 식별자, 명령어, 파일 경로, 오류 원문처럼 그대로 옮겨야 하는 것만 원래 표기를 둡니다.

## 발행

- **매일 자동 발행이 원칙입니다.** 00시 예약 작업이 `dev`에 초안을 올리고, 06시(한국 시간) `publish.yml`이 그날 호를 `main`·`deploy`로 올려 배포합니다. 사용자가 따로 멈추라고 하기 전까지 이 흐름을 바꾸거나 끄지 않습니다.
- 06시까지 사람이 승인하지 않은 초안은 검사를 통과하면 `approve.py --auto`로 자동 발행합니다. 이때 `review.auto: true`를 남기고 화면에는 '자동 발행'으로 표시합니다. 사람이 확인하지 않은 호에 사람 이름을 승인자로 적지 않습니다.
- 사람이 원문과 대조한 호만 `approve.py --by 이름`으로 승인하고, 화면은 '편집자 확인'으로 표시합니다.
- 오늘 호가 06시에 나가지 않았으면 원인(초안 없음, 검사 실패, 빨리 감기 불가)을 확인해 고친 뒤 Actions의 `아침 발행`을 수동 실행합니다.
