## 요청과 적용

| 영역 | 넓은 화면 | 좁은 화면 |
| --- | --- | --- |
| 이슈 추적 | 1,100px부터 선관위·무안공항 사안 카드 자체를 좌우 두 개로 배치 | 1,100px 미만에서는 한 열 |
| 추적의 긴 기록 | 폭 1,100px 이상·창 높이 600px 이상에서 카드 본문을 `min(72dvh, 42rem)` 안에서 스크롤 | 높이 제한 해제. 상세 근거는 건수를 표시한 펼침 영역에서 읽기 |
| 머리기사 옆 목록 | 901px부터 오른쪽 목록을 왼쪽 기사의 자연 높이에 맞춰 스크롤 | 900px 이하에서는 제한 해제, 보조 목록 기본 접기 |
| 언론 검색 | 1,100px부터 제목·설명 왼쪽, 검색창 오른쪽 | 설명 아래 전체 폭 검색, 입력 기능은 항상 표시 |
| 산업 비교 | 1,100px부터 요약·지표·출처 왼쪽, 품목별 그래프 오른쪽(1:1.2) | 세로 배치. 900px 이하에서는 상세 그래프 기본 접기 |
| 경제 핵심 지표 | PC 3~4개를 함께 보고 이전·다음·좌우 키·스와이프로 순환 | 한 카드 중심으로 읽고 다음 카드 일부 표시 |

머리기사 오른쪽 높이는 CSS grid stretch와 `contain:size`로 맞춥니다. JavaScript로 고정 픽셀을 계산하지 않아 큰 글자·글꼴·창 너비 변화에도 왼쪽 높이를 기준으로 삼습니다. 내부 스크롤 영역에는 이름과 키보드 포커스를 제공합니다.

산업의 핵심 수출입 지표와 품목별 그래프는 기준월이 다를 수 있습니다. 원래 월·출처를 유지하고 차트에서 기준월을 구분해 읽도록 안내했습니다.

## 펼침과 접기의 기준

**요약·현재 단계·다음 확인·주의사항·대표 숫자·원문 기준일·검색은 항상 표시합니다.** 보조 내용을 접어도 핵심 판단에 필요한 정보는 남깁니다.

| 내용 | PC 기본 상태 | 900px 이하 기본 상태 |
| --- | --- | --- |
| 전국 흐름, 보조 주제·숫자 | 펼침 | 접힘 |
| 진행 일정, 산업 그래프, 경제 집계 설명 | 펼침 | 접힘 |
| 관련 기사 표 3건 이하 | 펼침 | 접힘 |
| 관련 기사 표 3건 초과 | 접힘, 건수 표시 | 접힘, 건수 표시 |

공통 `responsiveDisclosure()`는 화면 폭별 사용자 선택을 기억하고 반복 렌더의 중복 연결을 막습니다. 닫힌 보조 숫자로 메뉴 이동을 선택하면 해당 영역을 먼저 펼칩니다. 경제 카드의 기준일은 집계 설명을 접어도 보입니다.

## 경제 순환 슬라이드

Swiper 14.4.0의 공식 압축 파일을 [로컬 vendor](../../dev/web/assets/vendor/swiper/README.md)에 보관했습니다. 라이선스·원본 주소·SHA-256을 기록했으며 외부 CDN 실행이나 CSP 허용 출처는 추가하지 않았습니다. 경제 섹션 800px 전에서 CSS·JS를 비동기로 불러와 첫 지면 준비를 막지 않습니다.

자동 넘김은 8초 간격이며 이전·다음, 재생 토글과 현재 위치를 제공합니다.

- 마우스 호버·키보드 포커스·화면 밖·숨긴 탭에서는 멈춥니다.
- 모바일 터치나 출처·설명 열기 후에는 사용자가 다시 켜기 전까지 자동 넘김을 재개하지 않습니다.
- 동작 줄이기 설정에서는 자동 넘김이 기본으로 꺼집니다.
- 긴 설명은 전체 문장을 내부 스크롤로 읽습니다. 원문 출처도 보존합니다.
- 라이브러리 로드·초기화가 실패하거나 늦은 초기화가 읽던 위치를 바꾸게 되면 기존 전체 격자 목록을 유지합니다. 지표가 적으면 rewind 또는 이동 잠금을 사용합니다.

자동 검사는 총 148건입니다. 공개 지면은 320~1,920px, 라이트·다크·큰 글자, 이슈 두 열, 머리기사 좌우 높이, 검색·그래프 위치, 키보드 스크롤과 펼침 상태를 확인했습니다. 경제는 순환 경계·키보드·수치/설명 보존·출처 열기·자동 넘김·포커스/탭 숨김·동작 줄이기·라이브러리 실패를 검사했습니다.

운영 확인은 390·1440·1920px의 라이트·다크·일반/큰 글자 12개 조합을 포함했습니다. 실제 Swiper 로드 이후 실행 오류와 CSP 위반은 없었고, 추적 기사 링크·내용과 경제 수치·기준일·출처가 보존된 것을 확인했습니다. 이는 해당 코드와 환경의 기능 검증이며 실사용자 성과나 모든 브라우저의 호환성을 뜻하지 않습니다.
