# 2026.11.03 섹션 배치와 순환 탐색

**PC에서 한 화면에 비교할 수 있는 정보를 늘리고, 긴 내용은 읽는 영역 안에서 조절하도록 바꿨습니다.** 전국 뉴스 1면·이슈 추적 2면과 이후 섹션 순서는 유지합니다. 기사·수치·출처 데이터는 수정하지 않습니다.

## 요청과 적용

| 영역 | PC에서 바뀐 배치 | 모바일 동작 |
| --- | --- | --- |
| 이슈 추적 | 1,100px부터 선관위·무안공항 사안 카드 자체를 좌우 두 개로 배치. 요약·단계 뒤에 진행 정보와 타임라인을 읽음 | 한 열로 이어 읽기 |
| 추적의 긴 기록 | 창 높이 600px 이상에서 카드 본문을 `min(72dvh, 42rem)` 안에 두고 스크롤. 중복 기사 목록을 근거 표로 통합하고 상세 기사는 건수를 표시한 펼침 영역에 배치 | 높이 제한을 풀고 근거 기사도 필요할 때 펼침 |
| 머리기사 옆 목록 | 901px부터 오른쪽 주제·핵심 숫자 목록의 높이를 왼쪽 머리기사 자연 높이와 맞춤. 넘치는 부분은 내부 스크롤 | 900px 이하에서 제한 해제, 기사 다음에 목록 배치 |
| 언론 검색 | 1,100px부터 제목·설명 왼쪽, 검색창 오른쪽 | 설명 아래 전체 폭 검색 |
| 산업 비교 | 1,100px부터 요약·지표·출처 왼쪽, 품목별 수출 그래프 오른쪽(1:1.2) | 설명·지표 다음 그래프. 그래프의 값과 증감은 두 줄로 구분 |
| 경제 핵심 지표 | PC 3~4개를 함께 보며 이전·다음·좌우 키·스와이프로 순환 | 한 카드 중심으로 읽고 다음 카드 일부를 표시 |

머리기사 오른쪽 높이는 JavaScript로 고정 픽셀을 계산하지 않습니다. CSS grid stretch와 `contain:size`로 왼쪽 높이를 기준으로 삼아 큰 글자·글꼴·창 너비 변화에 대응합니다. 스크롤 영역은 이름과 키보드 포커스를 제공합니다.

산업의 핵심 수출입 지표와 품목별 수출 그래프는 기준월이 다를 수 있습니다. 기존 데이터의 월·출처를 유지하고 차트 영역에 기준월을 구분해 읽도록 안내합니다.

## 펼침과 접기의 기준

요약·현재 단계·다음 확인·주의사항·대표 숫자·원문 기준일·검색은 항상 표시합니다. PC는 전국 흐름, 보조 주제/숫자, 진행 일정, 산업 그래프와 경제 집계 설명을 기본으로 펼치고 사용자가 닫을 수 있게 합니다. 모바일 900px 이하에서는 이 부가 영역을 기본으로 접습니다. 근거 기사처럼 긴 기록은 3건을 넘으면 PC에서도 접어 두고 건수를 표시합니다.

공통 `responsiveDisclosure()`가 화면 폭별 사용자 선택을 기억하고 반복 렌더의 중복 연결을 막습니다. 모바일에서 닫힌 보조 숫자로 메뉴 이동을 선택하면 해당 영역을 먼저 펼칩니다. 경제 카드의 기준일은 설명의 펼침 상태와 무관하게 항상 보입니다.

## 경제 순환 슬라이드

Swiper 14.4.0의 공식 압축 파일을 [로컬 vendor](../../dev/web/assets/vendor/swiper/README.md)에 보관합니다. 라이선스·원본 주소·SHA-256을 기록했으며 외부 CDN 실행이나 CSP 허용 출처를 추가하지 않습니다. 경제 섹션 800px 전에서 CSS·JS를 비동기로 불러오므로 첫 지면 준비를 막지 않습니다.

자동 넘김은 8초 간격입니다. 이전·다음 이동, 재생 토글, 현재 위치를 함께 제공합니다. 마우스 호버·키보드 포커스·화면 밖·숨긴 탭에서는 멈춥니다. 모바일 터치와 출처 열기 등 직접 읽는 동작은 자동 넘김 의도를 꺼서 사용자가 다시 켜기 전까지 재개하지 않습니다. 동작 줄이기 설정에서는 자동 넘김이 기본으로 꺼집니다.

기준·집계 설명이 긴 카드는 높이를 제한한 설명 영역에서 전체 문장을 스크롤해 읽습니다. 원문 출처도 보존합니다. 라이브러리 로드·초기화에 실패하거나 늦게 준비되어 이미 읽던 위치를 바꾸게 되는 경우 기존 전체 격자 목록을 유지합니다. 지표가 적으면 rewind 또는 이동 잠금을 사용합니다.

## 확인 범위

Python 56건, 공개 지면 Chromium 68건, 관리자 Chromium 21건, CSP Chromium 3건을 확인했습니다. 데이터 16개 호의 배포 규칙과 토큰 일치도 통과했습니다. 공개 지면에서는 320~1,920px, 라이트·다크·큰 글자, 이슈 좌우 배치, 머리기사 좌우 높이, 검색·그래프 위치, 키보드 스크롤과 근거 펼침을 확인합니다. 경제 검사는 순환 경계·키보드·전체 수치/설명 보존·출처 열기·자동 넘김·포커스/탭 숨김·동작 줄이기·라이브러리 실패 목록을 다룹니다.
