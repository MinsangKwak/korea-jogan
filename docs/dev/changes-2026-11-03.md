# 2026.11.03 두괄식 문구와 화면 모드 개선

**2026.11.03의 첫 변경 묶음으로, 문구·화면 모드·읽기 상태를 개선한 기록입니다.** 당시 최신호의 서술과 공개 지면을 다듬었으며 전국 뉴스 1면·이슈 추적 2면 순서는 유지했습니다.

같은 날의 반영 순서는 **이 문서 → [지면·삽화·보안](changes-2026-11-03-layout.md) → [섹션 배치·모바일 읽기](changes-2026-11-03-sections.md)**입니다. 현재 펼침 기본값과 지면 배치는 마지막 기록과 [디자인 가이드](../../design/guide.md)를 기준으로 읽습니다.

## 당시 바꾼 내용

| 영역 | 변경 | 확인 기준 |
| --- | --- | --- |
| 최신호·추적 문구 | 결론·변화를 앞세우고 수치·근거와 배경을 뒤에 배치 | 기사 제목·숫자·링크·날짜·review·단계 상태 보존 |
| 긴 요약 | 첫 문장과 나머지 설명을 시각적으로 분리 | textContent는 원본 문자열 유지 |
| 화면 모드 | 기기 설정·라이트·다크, 선택 저장, 전체 메뉴·관리자와 동기화 | 기기 변경과 저장소 차단·잘못된 저장값 처리 |
| 색 대비 | 라이트 지면의 흰 글자 발행 배지 수정, 다크 기사·도구 면 구분 | 토큰 기반 배경·글자·테두리, 배지 대비 4.5:1 이상 |
| 글자 확대 | 대표 제목과 추적 요약·단계를 rem 중심으로 조정 | 큰 글자 실제 크기 증가와 모바일 가로 넘침 검사 |
| 전국 뉴스 흐름 | 필요할 때 펼치는 기본 details로 변경 | 전체 요약에 접근 가능, 기사 목록까지 이동 단축 |
| 추적 모달 | 스크롤 중 닫기 헤더 유지, 상세의 반복 요약·단계 제거 | 닫기 버튼 위치와 복귀, 기사·타임라인 접근 유지 |

최신호의 서술 55개 필드와 추적의 summary·next·note 6개를 다듬었습니다. 예를 들어 보금자리론 안내는 금리 인상 결과를 먼저, 인천발 KTX는 연내 개통이 어려워졌다는 결론을 먼저 배치했습니다. 선관위 추적은 남은 감정 의뢰·결과 발표를, 무안공항 추적은 계속되는 원인 조사를 먼저 설명합니다. 해당 문구의 숫자와 확정·계획·혐의 상태는 유지했습니다.

## 구현 위치

- `core/theme.js`: 인라인 첫 모드 적용 이후 비동기로 선택·저장·기기 변경·다른 탭 동기화
- `core/ui.js`: 내용 손실 없이 긴 요약을 나누는 readingText
- `build_tokens.py` → `tokens.css`: 라이트·다크 선택자와 네이티브 조작 요소의 color-scheme 생성
- `editorial.css`: 공개 지면의 테마 대비·읽기 위계·큰 글자·모달 헤더
- `components/track`, `national`, `lead`, `nav`: 중복 제거·펼침·요약·키보드 탐색

## 당시 검증

Python 53건, 공개 지면 Chromium 51건, 관리자 Chromium 21건을 통과했습니다. 데이터 검사 16개 호와 토큰 생성 결과 일치도 확인했습니다. 브라우저 검사는 320~1440px, 라이트·다크, 큰 글자, 최신·지난 호, 로딩·오류와 추적 패널을 포함합니다. 새 검사는 모드 저장·기기 연동·저장소 차단, 선택 동기화, 배지 대비, 요약 문자열 보존, 모달 헤더 위치와 전국 흐름 펼침을 확인합니다.

이 수치는 해당 변경 묶음의 실행 결과이며 이용자 행동 개선율이나 접근성 인증이 아닙니다. 당시 변경은 폴더·역할별 커밋을 유지해 `dev → main → deploy`로 반영했습니다. 같은 날의 후속 섹션 변경은 별도 요청에 따라 squash했으므로 병합 방식도 각 기록의 적용 범위를 구분합니다.
