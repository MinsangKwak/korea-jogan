# GA4 운영 화면 연결과 확인

관리자 화면은 `/admin/`이며, 대한민국 조간 GA4 속성 `559927668`을 조회합니다. 기존 GitHub Pages 배포에 함께 포함되며 별도 서버나 서비스 계정 키를 사용하지 않습니다.

## 제공하는 정보

| 영역 | 기준 | 갱신 |
| --- | --- | --- |
| 오늘과 이번 주 | 오늘·최근 7일 방문자, 1인 평균 체류, 조회수 | 화면이 보일 때 5분마다, 수동 새로고침 시 즉시 |
| 이용 흐름 요약 | 선택 기간(오늘·최근 7일·최근 28일)의 방문자·조회수·세션·1인 평균 체류 | 5분마다, 기간 변경 시 즉시 |
| 방문자 추이·접속 기기 | 날짜별(오늘은 시간별) 방문자, 막대에 조회수 표시 · 기기별 방문자 | 이용 흐름과 함께 |
| 섹션별 체류 | `section_<id>` 읽은 사람, `dwell_<id>` 1인 평균·총 체류 시간 | 이용 흐름과 함께 |
| 많이 읽은 페이지·유입 채널·지역 | 경로별 조회수와 1인 평균 체류 · 채널별 세션 · 시도별 방문자 | 이용 흐름과 함께 |
| 최신 호·공개 호 수·확인 방식 | 배포된 공개 JSON | 페이지 진입·실패 후 재시도 |

최근 30분 실시간 영역은 2026-10-27에 뺐습니다. 운영에 필요한 것은 하루·한 주 단위 방문과 체류 시간이라는 판단입니다.

체류 시간은 두 가지입니다.

- **전체 체류**: GA4가 자동으로 재는 참여 시간(`userEngagementDuration`, 화면이 앞에 있던 시간)을 방문자 수로 나눈 값입니다.
- **섹션 체류**: 신문 화면(`dev/web/src/core/metrics.js`의 `trackSections`)이 직접 잽니다.
  - 화면 가운데 띠(위아래 45%를 뺀 영역)에 걸친 섹션을 지금 읽는 섹션으로 봅니다.
  - 탭이 숨겨진 동안과, 2분 넘게 스크롤·클릭·키 입력이 없을 때는 시간을 더하지 않습니다.
  - 모은 시간은 탭을 숨기거나 떠날 때 `dwell_<id>` 이벤트의 `value`(초)로 보냅니다. 관리자 화면은 이를 `eventValue`로 합칩니다.

`section_<id>`(읽은 사람)는 두 경우에 방문마다 한 번 보냅니다.

- 메뉴로 그 섹션을 골랐을 때
- 그 섹션에 3초 넘게 머물렀을 때

스크롤로 스쳐 지나간 섹션은 세지 않습니다. 이벤트 이름에 섹션을 담기 때문에 GA4에 맞춤 측정기준을 따로 등록하지 않아도 됩니다. `dwell_<id>`와 메뉴 클릭 집계는 2026-10-27 배포부터 쌓입니다. 그 전의 `section_<id>`는 화면 가운데를 지나기만 해도 세던 방식이라 수치를 그대로 비교하지 않습니다.

보고서는 모두 `hostName = korea-jogan.com`으로 제한합니다. 방문자는 차원 없는 집계를 사용하며, 페이지·기기별 사용자를 합쳐 계산하지 않습니다. 한 사람이 여러 페이지·기기를 사용할 수 있기 때문입니다. 지역은 GA4가 IP로 추정한 값이고, 국내 시·도 이름은 한국어로 바꿔 표시합니다.

기간별 보고서는 GA4의 처리 지연이 있으며 오늘의 값은 미완성일 수 있습니다. 발행 JSON 확인은 배포 파이프라인의 성공, 서버 가동률 또는 사람이 원문을 확인했다는 보장이 아닙니다.

## 최초 OAuth 설정

GA4 웹사이트에서 보고서를 읽을 수 있는 권한과 자체 웹 앱에서 API를 호출할 수 있는 OAuth 설정은 별개입니다. 최초 연결 시 다음 설정이 필요합니다.

1. Google Cloud 프로젝트에서 **Google Analytics Data API**를 사용 설정합니다.
2. Google Auth Platform에서 동의 화면의 앱 이름과 연락처를 설정합니다. 테스트 모드라면 관리자 Google 계정을 테스트 사용자로 등록합니다.
3. **웹 애플리케이션** 유형의 OAuth 클라이언트를 만들고, 승인된 JavaScript 원본에 `https://korea-jogan.com`을 추가합니다. 로컬에서 인증을 검사하려면 `http://localhost:8000`도 추가합니다. 원본에는 `/admin/` 경로를 붙이지 않습니다.
4. 데이터 접근 범위는 `https://www.googleapis.com/auth/analytics.readonly`만 요청합니다. 연결할 계정에 GA4 속성 `559927668`의 조회 권한이 있어야 합니다.
5. `/admin/`의 **처음 연결하는 경우 · Google OAuth 설정**에서 `…apps.googleusercontent.com` 형태의 공개 클라이언트 ID를 입력합니다. 클라이언트 보안 비밀이나 서비스 계정 JSON은 입력하지 않습니다.
6. **Google 계정으로 연결**을 누르고 계정 선택·동의를 완료합니다. Google 인증 도구가 늦게 준비되면 안내 후 연결 버튼을 다시 누릅니다.

클라이언트 ID는 이 브라우저의 `localStorage`에만 저장됩니다. 모든 기기에서 같은 ID를 쓰려면 공개 식별자를 `dev/web/admin/config.js`의 `clientId`에 설정해 다시 배포할 수 있습니다. 공개 ID는 비밀 값이 아니며, Google이 승인된 원본과 사용자 권한을 검사합니다. 웹 클라이언트 보안 비밀은 브라우저 코드에 넣지 않습니다.

기본 클라이언트 ID는 Google Cloud 프로젝트 `korea-jogan-admin`의 웹 클라이언트 `korea-jogan admin`입니다(2026-10-25 설정, 동의 화면은 테스트 모드·외부). 승인된 원본은 `https://korea-jogan.com`과 `http://localhost:8000`이며, 테스트 사용자로 등록된 계정만 연결할 수 있습니다. 실제 OAuth 인증과 운영 API의 종단 간 검증은 아직 남아 있습니다. Google Analytics에 로그인한 브라우저의 세션을 추출하거나 재사용하지 않습니다.

## 인증과 오류 처리

OAuth 토큰 모델을 사용해 브라우저에서 읽기 전용 단기 액세스 토큰을 받습니다. 토큰과 통계는 메모리에만 보관하고 저장소·URL·파일에 기록하지 않습니다. 관리자 문서에는 방문자 측정 코드를 넣지 않습니다. 로그인 전에는 통계를 요청하지 않으며, 화면 주소 자체는 공개되어도 보고서는 Google API가 계정별로 권한을 검사한 뒤 반환합니다. 별도의 사용자 관리·편집 권한·서버 관리자 기능은 없습니다.

- 연결 해제·인증 만료·401·403에서는 요청을 취소하고 표시한 통계를 지웁니다. 늦은 응답이 화면을 되살리지 못하게 세대 번호로 차단합니다.
- 팝업 종료·동의 거절·인증 도구 차단은 다시 연결할 수 있게 안내합니다.
- 요청은 12초 후 중단합니다. 일반 장애에서는 마지막 조회 결과와 시각을 유지하고 실패 안내를 표시합니다. 기간을 변경하면 이전 기간의 수치는 비웁니다.
- 429에서는 자동 갱신을 멈춥니다. 사용자가 잠시 후 새로고침하면 다시 시도합니다. 숨긴 탭에서도 자동 갱신을 중지합니다.
- 한 번 갱신할 때 `batchRunReports`를 두 번(5개·4개 보고서) 요청합니다. 하나라도 실패하면 이전 결과를 그대로 둡니다. 0명과 빈 목록은 오류로 처리하지 않습니다.

## 검증

```bash
cd dev/tests/browser
npm ci
npx playwright install chromium
npm test
```

`admin.cjs`는 로컬 테스트용 OAuth·GA4 응답을 브라우저 요청 경계에서 대체합니다. 실제 계정이나 운영 통계를 사용하는 검사가 아닙니다. 로그인 전 요청 차단, 설정 검증, 토큰 비저장, XSS 문자열 표시, 320~1440px 줄바꿈, 섹션 체류 계산, 0건, 401·403·429·500, API 비활성화, 조회 도중 권한 회수, 팝업 종료·거절, 기간 변경, 조회 실패·재시도, 늦은 응답 차단, 5분 갱신·숨긴 탭, 시간 초과, 만료, 공개 발행 정보 오류, 인증 도구 차단의 20개 시나리오를 검사합니다.

실제 연결 후에는 허용된 계정과 권한 없는 계정, GA4 보고서 원본과의 수치 비교, 기간 변경, 새로고침 후 재인증, 연결 해제까지 확인합니다. 테스트 통과만으로 운영 OAuth 설정이 완료되었다고 표현하지 않습니다.
