# 2026.11.04 검색 도착 페이지와 유입 점검

**기존 호·추적 사안·지표 기록을 고정 주소에서 찾도록 정리하고, 방문 감소를 판단할 측정 기준을 구분하는 작업입니다.** 일 1,000조회는 운영 목표이며 이 변경의 성과나 달성 보장이 아닙니다. 새 페이지는 기존 자료를 재구성하며 새 취재 기사나 실시간 지표를 만들지 않습니다.

## 배경: 방문 감소와 측정 변경

2026.11.04 사용자가 공유한 관리자 캡처의 최근 28일 수치는 **방문자 121명·조회수 126회·세션 131회·평균 참여 시간 4초**입니다. 채널별 세션은 Direct 127·Organic Search 2·Referral 2입니다. 별도의 GA4 홈 캡처에서는 지난 7일 Direct 37세션(-60.2%), Organic Search 0세션(이전 기간 대비 -100%), Referral 2세션이 보입니다.

두 캡처의 기간·조회 조건을 같다고 가정하지 않습니다. 검색 유입의 절대값이 작으므로 -100%를 곧바로 검색 노출의 급락으로 해석하지 않습니다. Direct 전체나 해외 방문 전체를 봇으로 분류하지도 않습니다. 이번 작업에서는 인증된 GA4·Search Console 원본 보고서를 재조회하지 않았습니다.

| 기존 변경 | 비교할 때의 영향 |

| 2026.10.30 자동화·내부 방문 제외 | 이전에 섞였던 배포 검증·운영 접속이 빠질 수 있어 실제 독자 감소와 분리해야 함 |

## 고정 주소에서 다시 찾는 구성

| 주소 | 담는 내용 | 기준과 한계 |
| --- | --- | --- |
| `/archive/` | 공개된 호를 최신 날짜부터 탐색 | 공개 목록의 17개 호. 초안·미공개 호 제외 |
| `/topics/` | 추적 사안 모음 | 기존 선관위 특검·무안공항 참사 2개 |
| `/topics/<사안 ID>/` | 요약·진행 단계·다음 확인·일정·관련 기사 | 기존 추적 데이터의 표현·근거 범위 유지 |
| `/indicators/` | 핵심 지표 모음 | 코스피·코스닥·원달러 환율·두바이유·휘발유·기준금리 6개 |
| `/indicators/<지표>/` | 여러 호에 실린 값·변동·기준일·출처 | 호별 스냅샷. 같은 원자료가 반복될 수 있음 |

호의 날짜와 원자료 기준일은 다를 수 있습니다. 휴장·발표 대기·집계 시차를 새 관측값으로 바꾸지 않습니다. 기존 값·출처·정정·사람 확인 여부도 재작성으로 덮어쓰지 않습니다.

각 페이지는 JavaScript 실행 전에도 읽을 본문과 내부 링크를 제공하고, 제목·설명·canonical·사이트맵을 실제 주소와 맞춥니다. 정적 페이지를 더 만든 사실과 Google이 색인한 사실은 별도로 확인합니다.

## 후속 검증과 유입 운영

1. 새 페이지의 HTTP 상태·정적 본문·내부 링크·canonical·사이트맵을 확인합니다. 초안이 포함되지 않는지 함께 검사합니다.
2. Search Console에서 **오늘을 제외한 완료된 최근 7일과 직전 7일**을 비교합니다. 최신 값이 미완성이면 확정된 날짜까지 같은 길이로 맞춥니다.
3. 국가 전체·대한민국을 각각 보고 검색어·페이지별 클릭·노출·CTR·평균 게재순위를 기록합니다. 페이지 색인·제외 사유와 대표 URL 검사도 확인합니다.
4. GA4도 같은 기간·호스트 조건으로 맞추고 검색 유입·읽기·원문 이동·재방문을 함께 봅니다. 10/30 이전 수치가 섞인 비교에는 측정 변경을 표시합니다.
5. 대표 사례의 외부 소개에는 UTM을 붙여 공유 매체를 구분합니다. 이 작업에서는 외부 글·메시지를 게시하거나 보내지 않습니다.

구체적인 보고서 순서·소개 소재·UTM 예시는 [검색·외부 소개 계획](../planning/backlinks.md)에 있습니다. 구조 개선만으로 검색 순위·조회 증가를 주장하지 않습니다.

## 아직 확인하지 못한 사항

- GA4 원본과 관리자 수치의 동일 조건 대조, 실제 신규·재방문 독자의 변화
- Search Console 최신 노출·검색어·색인·선택 canonical과 새 주소 반영 여부
- 외부 소개 게시 여부와 그 유입 성과
- 수정 후 빌드·자동 검사·배포·운영 페이지의 실제 확인 결과

이 항목은 완료 증거를 확보한 뒤 갱신합니다. 과거 운영 관찰이나 자동 테스트 통과로 실사용 성과를 대신하지 않습니다.
