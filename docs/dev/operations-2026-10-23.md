# 2026.10.23 운영 확인과 모바일 안정화

**발행 실패를 차단하고, 느린 접속·렌더링 오류에서도 요약과 재시도 경로를 남긴 작업 기록입니다.** 아래 수치와 예약 시각은 2026.10.23 확인 당시의 값입니다. 현재 운영 상태나 방문자 성과로 읽지 않습니다.

[최신 지면·모바일 변경](changes-2026-11-03-sections.md) · [현재 발행 절차](../planning/runbook.md) · [문서 안내](../README.md)

## 당시 운영 상태

확인 대상은 `https://korea-jogan.com/`과 `158314f`의 공개 데이터입니다. 발행·화면 동작과 방문 수치를 구분해 확인했습니다.

| 항목 | 2026.10.23 확인 결과 |
| --- | --- |
| 공개 호 | 5개, 최신 2026-10-23 |
| 최신 호 상태 | 자동 발행, 사람 확인 전 |
| 실제 발행 기록 | 한국 시간 08:47, `review.auto: true` |
| 당시 예약 시각 | 06:00. 이날 실제 기록은 목표보다 2시간 47분 늦음 |
| 최신 호 콘텐츠 | 전국 24건, 시도 48건, 언론 주제 3개·기사 30건 |
| 사이트 응답 | 첫 화면·발행 목록·최신 호 JSON 모두 HTTP 200 |
| Actions | 확인한 최근 실행 8건 모두 성공 |
| 측정 연결 | GA4 ID 연결, GoatCounter 주소 비어 있음 |
| 방문자·페이지뷰 실측 | 당시 연결 도구로 GA4 보고서를 조회할 수 없어 미확인 |

발행 시각은 JSON 기록과 Actions 실행 시각으로 확인했습니다. 이번 작업은 예약 시스템을 변경하지 않았습니다. 이후 예약·재시도 시각은 [현재 브랜치·발행 절차](branches.md)를 따릅니다.

### 응답 시간 측정의 범위

작업 환경에서 다시 측정한 TTFB는 첫 화면 5,127ms, 발행 목록 5,133ms, 최신 호 JSON 5,054ms였습니다. 최초 단일 확인의 첫 화면은 4,170ms였습니다.

이 값에는 네트워크·중계 경로가 포함됩니다. 한국 모바일 이용자의 평균 속도나 서버 자체 처리 시간을 뜻하지 않으며, 개선율을 산출하지 않았습니다.

## 적용한 안정화

| 영역 | 당시 적용한 내용 |
| --- | --- |
| 발행 검사 | 빈 주제, 잘못된 중첩 객체·배열·숫자, 중복 주제 ID, 비교 표 열 수 불일치를 차단. 깨진 JSON·발행 목록도 검사 실패로 보고 |
| 화면 복구 | 초기화 전체를 오류 경계로 처리. 렌더링 성공 후 정적 요약 제거, 실패 시 요약·오류 안내·재시도 유지 |
| 첫 진입 요청 | 배포 HTML에 호 JSON·발행 목록을 포함해 본문 전 별도 요청 2건 제거. 개발 화면·날짜 쿼리는 필요 시 파일 요청, 삽입 JSON의 `<`는 이스케이프 |
| 보조 요청 | 외부 글꼴 CSS의 본문 차단을 줄이고 정정 기록·최신 숫자는 본문 이후 처리 |
| 로딩·시간 초과 | 텍스트·표시자로 로딩 안내, 데이터 요청 12초 제한. 스크립트 누락 시 20초 후 재시도·정적 요약 제공. 움직임 줄이기 설정 반영 |
| 모바일 | 시도·주제 선택, 최신 숫자, 긴 값·비교 표를 폭 안에서 세로 배치. 페이지 전체를 가로로 잘라 숨기지 않음 |
| 데이터 표시 | 비교 카드 `pick`이 편집 메모이면 첫 값·마지막 값 사용. 미상 기사 날짜는 ‘발표일 미확인’으로 표시 |
| 메뉴 | 열린 직후 닫을 때 예약 프레임도 취소해 서랍이 다시 열리는 경쟁 상태 방지 |
| 측정 이벤트 | GA4에 `app_ready`·`app_load_error`와 초기화 시간 `duration_ms` 추가. 실제 집계는 GA4 보고서에서 별도 확인 |

## 당시 검증 결과

| 검사 | 결과 |
| --- | --- |
| 데이터·토큰 | 공개 5개 호의 배포 검사, 토큰 일치 검사 통과 |
| Python | 42건 통과 |
| 실제 Chromium | 22개 시나리오 통과 |
| 배포 페이지 | 본문 JSON을 다시 요청하지 않는 동작 확인 |
| 구문·차이 검사 | JavaScript 구문 검사, `git diff --check` 통과 |
| 외부 정적 UI 검사 | 인라인 이벤트가 없다는 항목 9건 잔존. 별도 JS 연결을 인식하지 못한 결과이며 통과로 보고하지 않음 |

Chromium은 320·360·390·430·768·900·1440px, 일반·큰 글자와 공개 호 5개를 확인했습니다. 날짜 쿼리, 느린 요청, 404, 빈 주제, 렌더링 오류, 스크립트 누락·시간 초과, 메뉴·Esc·포커스, 지역 선택, 비교 표·검색, 보조 데이터 오류를 포함했습니다. 메뉴·크기·검색의 실제 동작은 이 브라우저 검사로 확인했습니다.

로컬 파일을 HTTP 응답으로 제공하고 오류를 주입하는 검사를 CI에도 추가했습니다. iOS Safari 실기기와 실제 느린 이동통신 환경은 이 검증 범위에 포함하지 않았습니다.
