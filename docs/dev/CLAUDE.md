# Claude 작업 지침

## 언어

말도 글도 한국어로만 씁니다. 사용자에게 하는 답변·진행 안내·질문·요약은 물론이고, PR 제목·본문, 커밋 메시지, 이슈·리뷰 댓글, 문서까지 모두입니다.

원래 표기를 두는 건 코드 식별자, 명령어, 파일 경로, 오류 원문처럼 그대로 옮겨야 하는 것뿐입니다. 커밋 제목은 [commits.md](commits.md) 규칙을 따릅니다.

## 발행

**매일 자동 발행이 원칙입니다.** 사용자가 멈추라고 하기 전에는 이 흐름을 바꾸거나 끄지 않습니다. 00시 예약 작업이 `dev`에 초안을 올리면, 06시(한국 시간) `publish.yml`이 그날 호를 `main`·`deploy`로 올려 배포합니다.

승인 표시는 누가 확인했느냐로 갈립니다.

- 사람이 원문과 대조한 호만 `approve.py --by 이름`으로 승인합니다. 화면에는 '편집자 확인'이 뜹니다.
- 06시까지 승인되지 않은 초안은 검사를 통과하면 `approve.py --auto`로 나갑니다. `review.auto: true`가 남고, 화면에는 '자동 발행'이 뜹니다. 사람이 보지 않은 호에 사람 이름을 승인자로 적지 않습니다.

06시에 호가 나가지 않았다면 원인부터 찾습니다. 초안이 없는지, 검사에 걸렸는지, 빨리 감기가 막혔는지 확인해 고친 뒤 Actions의 `아침 발행`을 수동 실행합니다.
