## 화면 구성

1200px 이상에서는 화면 오른쪽 가운데에 세로 메뉴가 늘 떠 있고, 861~1199px에서는 분류 메뉴가 스크롤 내내 위에 붙어 있으며, 860px 이하에서는 하단 탭바로 섹션을 옮겨 다닙니다. 메뉴 오른쪽 끝(모바일은 탭바의 '메뉴')의 **전체 메뉴**를 누르면 오른쪽에서 서랍이 열립니다. 여기서 모든 섹션과 그 안의 항목(언론 주제, 전국 분야, 시도)으로 바로 가고, 글자 크기·공유·지난 호·정정 기록·오류 신고도 엽니다. BBC·NYT와 국내 일간지 사이트의 '고정 상단 바 + 전체 메뉴' 배치를 참고했습니다.

헤더는 제호 한 줄(로고 · 날짜·수집 시각·편집자 확인 · 공유·글자 크게)과 '최신 공식 숫자' 띠 두 단으로 둡니다. 편집자 확인을 마친 정상 호는 제호 안의 '✓ 편집자 확인' 표시로만 알리고, 초안·시안·미발행처럼 독자가 알아야 할 상태일 때만 전체 폭 안내 띠를 띄웁니다. 600px 이하에서는 공유·글자 크게 단추를 아이콘으로 줄이고, 최신 숫자는 한 줄로 두고 가로로 밀어 봅니다.

긴 목록은 항목이 3개를 넘으면 앞의 3개만 보이고 아래 '더보기 (N건)' 단추로 펼칩니다. 오늘 꼭 볼 숫자, 언론사별 기사, 기준이 갈린 숫자, 전국 뉴스, 시도별 한 줄과 시도 기사, 이번 주 일정, 주력산업, 수집 방법과 한계에 적용합니다. 핵심 숫자 타일과 그래프, AI 요약처럼 한눈에 비교해야 하는 것은 접지 않습니다.

| 메뉴 | 내용 |
| --- | --- |
| 홈 | 머리기사·요약·핵심 수치 3개, 오늘 꼭 볼 숫자, 오늘 기준이 갈린 숫자 카드 |
| 언론 | 주제·키워드 검색. 위에는 AI 요약과 기준이 갈린 숫자, 아래에는 언론사별 기사 제목과 링크만 |
| 전국 | 분야별 전국 뉴스(사회·사건·안전·날씨·재난·안보·외교·국제·과학·IT·생활·물가·문화·스포츠)와 흐름 요약 3줄 |
| 지역 | 수도권·강원·충청·호남·영남·제주 권역으로 묶은 17개 시도. 시도를 누르면 지역 언론 기사, 고르기 전에는 시도별 한 줄 요약. 900px 이하에서는 시도 단추를 한 줄로 밀어 봅니다 |
| 정치 | 대통령 임기 경과율, 선거·예산 처리기한 D-Day, 이번 주 일정. 정당 공방과 인물 평가는 넣지 않습니다 |
| 경제 | 증시·환율·유가 핵심 숫자. 상승·보합·하락 방향만 표시하고 좋고 나쁨을 평가하지 않습니다 |
| 산업 | 반도체 밖의 주력산업(철강·조선·자동차·석유화학·에너지)과 수출입 |
| 재정 | 국가채무 연도별 추이(결산·전망 구분), 월간 재정동향, 국민연금 자산 배분과 개혁 내용 |

제호 아래 '최신 공식 숫자' 띠는 승인된 조간과 별개로, 한국은행 ECOS의 코스피·코스닥 종가, 원·달러 환율, 기준금리를 평일 낮 1시간마다 다시 받아 보여 줍니다. '자동 갱신 · 사람 확인 전'으로 표시해 조간 숫자와 구분합니다. ECOS는 장중 시세를 주지 않아, 새 일별 확정값이 나오면 다음 갱신 때 반영됩니다.

바닥글에는 수집 한계, 출처 신뢰도, 지난 호 목록, RSS, 정정 기록과 오류 신고, 만든 사람 링크가 있습니다. 제호의 '공유' 단추는 지금 보는 호의 링크를 건넵니다.

호마다 고유 주소(`https://korea-jogan.com/YYYY-MM-DD`)가 있습니다. 배포할 때 `build_pages.py`가 호별 제목·설명·대표 주소와 머리기사·숫자·기사 제목 요약을 HTML에 미리 넣어, JavaScript를 실행하지 않는 검색 로봇도 내용을 읽습니다. 화면이 그려지면 이 요약은 지워집니다. 예전 주소(`?d=YYYY-MM-DD`)도 그대로 열립니다.

2026-10-20호에는 전국 뉴스 24건, 시도 뉴스 43건, 언론 주제 3개(국내외 기사 40건, 기준이 갈린 숫자 6개), 국가채무 14개 연도를 담았습니다.

## 디렉터리

화면은 빌드 없이 브라우저가 바로 읽는 정적 파일입니다. 공통 코드(`core`)와 화면 단위 컴포넌트(`components`)를 나누고, 컴포넌트마다 JS와 CSS를 한 폴더에 둡니다. 데이터 파이프라인 스크립트는 수집 → 빌드 → 발행 역할별로 나눴습니다.

```text
korea-jogan/
├── public/                           GitHub Pages로 배포하는 정적 사이트. 이 폴더만 배포됩니다
│   ├── index.html                    마크업과 메타데이터. 스타일·스크립트는 src/에서 읽습니다
│   ├── src/
│   │   ├── styles/
│   │   │   ├── tokens.css            디자인 토큰 CSS 변수. design/tokens.json에서 만듭니다(손으로 고치지 않음)
│   │   │   ├── kj.css                디자인 시스템 컴포넌트(kj- 접두사)
│   │   │   └── layout.css            페이지 공통 배치(본문 폭, 다단)
│   │   ├── core/                     여러 컴포넌트가 함께 쓰는 코드
│   │   │   ├── config.js             섹션·탭·권역 상수와 화면 상태
│   │   │   ├── format.js             숫자·날짜 서식
│   │   │   ├── ui.js                 요소 생성, 목록 접기, 아이콘, 출처 펼치기, 뉴스 항목
│   │   │   ├── data.js               발행 데이터 불러오기
│   │   │   ├── metrics.js            GoatCounter·GA4 측정
│   │   │   └── seo.js                호에 맞춘 제목·대표 주소
│   │   ├── components/               화면 단위. 폴더마다 <이름>.js와(필요하면) <이름>.css

│   │   │   ├── national/             전국 뉴스
│   │   │   ├── regions/              지역(권역별 시도)
│   │   │   ├── politics/             정치 일정·D-Day
│   │   │   ├── economy/              핵심 숫자·최신 공식 숫자 띠
│   │   │   ├── industry/             주력산업·수출입
│   │   │   ├── fiscal/               국가채무·국민연금
│   │   │   └── footer/               수집 한계·지난 호·정정 기록
│   │   └── main.js                   진입점. 데이터를 읽고 컴포넌트를 차례로 그립니다
│   ├── assets/images/                공유 미리보기(og.png)·파비콘·앱 아이콘. scripts/tools/og/에서 만듭니다
│   ├── data/
```

## 브랜치와 배포

```text
main ──(맞춤)──▶ dev ──(PR 병합)──▶ main ──(그대로 올림)──▶ deploy ──▶ GitHub Pages
```

| 브랜치 | 역할 |
| --- | --- |
| `dev` | 개발 중인 소스와 데이터. 모든 작업과 일일 발행이 여기서 시작합니다 |
| `main` | 검사를 통과한 최종본 |
| `deploy` | 배포 전용. 여기에 올라온 커밋만 GitHub Pages에 나갑니다 |

`main`과 `deploy`에는 직접 커밋하지 않습니다. 자세한 순서와 저장소 설정은 [docs/guides/BRANCHES.md](docs/guides/BRANCHES.md)에 있습니다. 커밋 제목은 [docs/guides/COMMITS.md](docs/guides/COMMITS.md)의 `종류(범위): 제목` 꼴을 따릅니다.

## 매일 발행

매일 00시(한국 시간) Claude 예약 작업이 [docs/guides/DAILY_RUNBOOK.md](docs/guides/DAILY_RUNBOOK.md) 절차대로 그날 호를 만듭니다.

1. 분야별 하위 에이전트가 공식 발표와 기사를 동시에 조사합니다(핵심 숫자 · 전국 · 지역 두 묶음 · 언론 주제).
2. 결과를 합쳐 `public/data/issues/YYYY-MM-DD.json`을 쓰고 `index.json`의 `latest`를 바꿉니다.
3. `status: "draft"`로 두고 `scripts/publish/validate.py`를 통과하면 `data(issue): YYYY-MM-DD호 초안`으로 `dev`에 커밋합니다.
4. 06시 전에 사람이 머리기사·핵심 숫자·갈린 숫자를 원문과 대조했으면 `scripts/publish/approve.py --by 이름`으로 승인합니다('편집자 확인').
5. 06시(한국 시간) `publish.yml`이 승인되지 않은 초안을 `--auto`로 자동 발행하고, `main`과 `deploy`를 같은 커밋으로 빨리 감기합니다. 이어서 `deploy-pages.yml`이 검사하고 RSS를 만든 뒤 배포합니다.

검사에 실패하면 올리지 않습니다. 재정·국민연금·수출입 같은 상설 지표는 새 공식 발표가 있을 때만 바꿉니다.

## 로컬에서 보기

`index.html`은 JSON을 `fetch`로 읽기 때문에 파일을 바로 열면 데이터가 비어 보입니다. 간단한 서버로 엽니다.

```bash
python3 -m http.server -d public 8000
# http://localhost:8000
```

데이터를 고친 뒤에는 검사를 돌리고, 커밋 제목 훅을 켜 둡니다.

```bash
python3 scripts/publish/validate.py
python3 -m unittest discover -s tests
git config core.hooksPath .githooks
```

실행 기준은 CI와 같은 Python 3.12 · Node 22입니다.

## 데이터 원칙

- 숫자는 공식 발표 원문이나 그 발표를 인용한 기사에 있는 것만 씁니다. 기억이나 추측으로 채우지 않습니다.
- 잠정·확정·전망과 발표일·기준일·수집일을 구분합니다. 출처마다 신뢰도 등급(A 공식 확정 ~ E 분석·계산)을 붙입니다.
- 기사 본문을 읽지 못하고 검색 요약만 봤으면 그 사실을 데이터에 남깁니다(`read`·`body_read`).
- 기사 본문은 저장·재배포하지 않습니다. 제목·직접 쓴 짧은 요약·링크만 둡니다.
- 정부·정당·인물을 평가하지 않습니다.

## 알려진 한계

- 여러 국내외 매체가 robots.txt나 서버 차단으로 AI의 본문 접근을 막습니다. 기사 목록은 언론사 RSS(26곳)로 넓혔지만, 본문을 읽고 숫자를 비교하는 일은 열린 매체에서만 합니다. 막힌 매체 기사는 '본문 미확인'으로 표시하고, 대체한 사실을 화면 하단 '수집 방법과 한계'에 적습니다. 자세한 내용은 [일일 발행 절차](docs/guides/DAILY_RUNBOOK.md#접속이-막힌-매체)에 있습니다.
- 공공 API는 한국은행 ECOS만 붙었습니다. '최신 공식 숫자' 띠는 ECOS에서 받지만, 조간 본문의 숫자는 아직 공식 발표 원문과 기사를 조사해 채웁니다.
- ECOS 환율은 매매기준율이라, 조간의 주간 종가 환율과 소수점 아래가 다를 수 있습니다.
- 방문 측정(GoatCounter)은 주소를 넣어야 켜집니다. 지금은 꺼져 있습니다.
