# 디자인 방향과 공통 UI 기준

**신문의 정보 위계를 바탕으로, 숫자와 출처를 오래 읽을 수 있는 화면을 설계했습니다.** 시각적 장식보다 제목·값·기준·출처의 관계가 먼저 보이도록 정리했습니다.

[서비스](https://korea-jogan.com/) · [토큰 원본](tokens.json) · [공통 스타일](../dev/web/src/styles/kj.css)

## 이름과 화면의 방향

‘조간’은 하루 한 호를 아침에 읽는 사용 상황을 나타냅니다. ‘대한민국’은 전국 17개 시도와 정치·경제·산업·재정을 함께 다룬다는 범위입니다. 새로고침할 때마다 이어지는 피드보다, 날짜가 있는 한 호를 읽고 마치는 구조에 맞춰 이름과 화면을 정했습니다.

검은 제호, 굵은 머리기사, 섹션을 나누는 괘선은 종이 신문의 정보 위계를 참고했습니다. 이 표현이 신뢰를 높인다는 사용자 검증 결과가 있는 것은 아닙니다. 발행 단위와 정보의 중요도를 눈에 보이게 만들기 위한 선택입니다.

| 결정 | 적용 | 의도 |
| --- | --- | --- |
| 제호와 본문 분리 | 밝은 지면에는 흰 배경·검은 글자, 어두운 지면에는 어두운 배경·밝은 글자 | 매체 이름·날짜·확인 상태를 한곳에서 인식 |
| 선으로 영역 구분 | 제목 위 3px 괘선, 항목 사이 1px 구분선 | 정보가 많은 화면의 위계 유지 |
| 머리기사 한 개 | 명조 서체의 큰 제목은 주요 뉴스에 사용 | 분야 목록과 대표 기사 사이의 위계 구분 |
| 본문은 평면 구성 | 그림자는 고정 메뉴·서랍 등 떠 있는 요소에 사용 | 본문과 조작 영역 구별 |
| 제한된 강조 | 청색은 탐색·주요 행동, 호박색은 전통 산업·안내 | 색의 역할 유지 |

## 숫자에 평가를 섞지 않는 표현

상승·하락은 색 대신 기호와 글자로 전달합니다. 빨강·파랑의 시장 관습을 그대로 쓰기보다 값의 방향과 의미를 분리하려는 결정입니다. 오류색 `danger`는 데이터 하락이 아닌 불러오기 실패 등에 사용합니다.

출처의 성격은 A~E 문자로, 결산·전망은 배지와 선 형태로 구분합니다. 확인하지 못한 연도는 그래프를 추정해 채우지 않고 미확인으로 표시합니다. 색을 구분하기 어려워도 핵심 의미가 남아야 합니다.

## 글자와 정보 밀도

제호·주요 뉴스 제목은 Noto Serif KR, 본문 기본 글꼴은 Noto Sans KR이며 기기 기본 한글 글꼴을 대체 글꼴로 둡니다. 본문은 400, 보조 강조는 500·700, 제목과 대표 숫자는 900 굵기를 사용합니다. 숫자는 `tabular-nums`로 자릿수 비교를 돕습니다.

기준 글자는 17px, 900px 이상에서는 18px입니다. 글자 크게 기능은 21px 기준으로 전환하고 선택을 기기에 저장합니다. 설명 문단의 최대 너비는 `42rem`입니다. 글자 크기 토큰의 최솟값은 `caption` 0.8rem이며, 현재 최신 숫자 띠와 지역 선택의 일부 보조 표기는 0.75rem 예외가 있습니다.

목록은 기본 3건을 먼저 보여 주고 나머지는 더보기로 엽니다. 숫자 카드·그래프·AI 요약처럼 비교를 위해 함께 봐야 하는 정보는 접지 않습니다. 수치 비교가 다른 기사 목록 아래에 묻히지 않도록 홈에도 비교 카드를 배치했습니다.

## 화면 폭에 따른 탐색

| 화면 폭 | 주요 탐색 | 유지할 동작 |
| --- | --- | --- |
| 901px 이상 | 상단 고정 분야 메뉴·추적 막대·전체 메뉴 | 현재 섹션 표시, 패널 열기·숨기기 |
| 900px 이하 | 축약한 상단 분야 메뉴·추적 재진입·전체 메뉴 | 한 열 읽기, 도구 이름 표시와 배지 줄바꿈 |
| 모든 화면 폭 | 맨 위로 버튼 | 한 화면 넘게 스크롤하면 표시, 이동 후 제호에 포커스 |
| 900px 이하 지역 선택 | 권역별 줄바꿈 | 모든 시도를 화면 폭 안에서 확인 |

하단 탐색은 고정하지 않고 문서 흐름 안에 둡니다. 기존 오른쪽 세로 메뉴는 공개 지면에서 숨기며, 관련 여백도 해제합니다.

모든 탐색은 `SECTIONS`를 공유합니다. 전체 메뉴에서는 주제·분야·시도까지 바로 이동하며, 해당 목록이 접혀 있으면 필요한 항목을 펼칩니다. 화면별 메뉴를 따로 수정해 명칭이나 순서가 달라지지 않게 합니다.

## 토큰 관리

색과 크기를 바꿀 때는 [tokens.json](tokens.json)을 먼저 수정하고 CSS를 다시 생성합니다.

```bash
python3 dev/pipeline/build/build_tokens.py
python3 dev/pipeline/build/build_tokens.py --check
```

생성 파일은 `dev/web/src/styles/tokens.css`입니다. CI는 원본과 생성 결과의 일치 여부를 검사합니다. 대비·포커스·줄바꿈 등 실제 사용성은 화면에서 따로 확인해야 합니다.

### 색

| 토큰 | 역할 | 사용 기준 |
| --- | --- | --- |
| `bg`, `surface`, `surface-raised` | 본문 바탕·구분 영역·상위 패널 | 깊이가 필요한 경우에만 단계 추가 |
| `ink`, `ink-2`, `ink-3` | 제목·본문·보조 정보 | 보조 정보도 읽을 수 있는 대비 유지 |
| `line`, `line-strong` | 장식 구분선·조작 요소 경계 | 조작 요소의 유일한 경계에는 `line-strong` 사용 |
| `brand`, `brand-strong`, `brand-soft`, `on-brand` | 주요 행동·선택·강조 배경·그 위 글자 | 밝은·어두운 테마의 조합을 함께 확인 |
| `hl`, `hl-soft` | 전통 산업·안내 | 일반 강조색으로 남용하지 않음 |
| `head`, `head-ink`, `head-line` | 제호와 제호 안 조작 요소 | 검은 배경에 글자·경계 식별 |
| `danger`, `danger-soft` | 오류 | 수치 하락에 사용하지 않음 |
| `bar`, `chart-1`~`chart-6` | 그래프 계열 | 문자 범례와 함께 사용 |
| `focus`, `scrim` | 포커스·서랍 뒤 가림막 | 현재 조작 위치와 활성 영역 전달 |

밝은 테마의 주요 청색은 `#0047a0`, 산업 강조는 `#a14a00`입니다. 어두운 테마 값은 토큰 원본에 별도로 정의하며 `prefers-color-scheme`에 따라 적용합니다.

### 글자 단계

| 토큰 | 크기 | 용도 |
| --- | --- | --- |
| `display-1`, `display-2` | 최대 2.6rem, 1.9rem | 머리기사·섹션 제목. 좁은 화면에서는 유동 크기 적용 |
| `title-lg`, `title`, `title-sm` | 1.5rem, 1.25rem, 1.05rem | 제호·패널·기사 제목 |

| `label`, `meta`, `caption` | 0.9rem, 0.85rem, 0.8rem | 메뉴·출처·범례 |

### 간격과 형태

간격은 `space-1`부터 `space-10`까지 정의된 단계를 사용합니다. 카드 안은 `space-4`, 섹션 위아래는 `space-10`을 기준으로 합니다. 모서리는 막대 2px, 배지 4px, 카드 8px, 버튼·칩은 pill입니다. 선은 1px 구분선과 3px 괘선·포커스를 기준으로 합니다.

## 접근성 확인 기준

본문 대비 4.5:1, 주요 비문자 요소 3:1, 조작 영역 44px 이상을 설계 목표로 둡니다. 이 문서는 인증이나 전체 화면의 적합성 판정 결과가 아닙니다. 변경할 때 밝은·어두운 테마와 글자 확대 상태를 확인합니다.

- 키보드 포커스는 3px 테두리와 2px 간격으로 표시하고, 제호 위에서는 흰색을 사용합니다.
- 전체 메뉴를 열면 포커스를 안으로 이동·제한하고 닫으면 열기 버튼으로 돌려줍니다.
- 현재 위치는 `aria-current`, 펼침 상태는 `aria-expanded`로 전달합니다.
- `prefers-reduced-motion`에서는 부드러운 스크롤과 서랍 이동·로딩 애니메이션을 줄이거나 끕니다.
- 색 외에 기호·글자·모양을 함께 제공합니다.

## 문구 작성 기준

결론을 첫 문장에 쓰고 `~합니다`·`~했습니다`체로 짧게 설명합니다. 증감에는 비교 대상과 기간을 붙입니다. 확인되지 않은 숫자를 ‘약’으로 만들어 넣지 않습니다. 출처가 대략값을 제공한 경우에만 그 정밀도에 맞춰 적고, 확인하지 못한 값은 빼거나 미확인으로 표시합니다.

새 섹션을 추가할 때는 기존 토큰·컴포넌트·상태 처리부터 확인합니다. 이름과 디자인 방향, 구현 규칙이 같은 기준으로 이어지도록 유지합니다.

## 로딩과 모바일 줄바꿈

첫 접속에서는 읽기 준비 상태를 텍스트와 표시자로 알립니다. 각 데이터 요청은 최대 12초 뒤 중단하며, 스크립트가 실행되지 않으면 20초 후 재시도 링크와 미리 생성한 호 요약을 제공합니다. 정정 기록·최신 숫자 요청은 본문이 준비된 뒤 처리하며 본문 표시를 지연시키지 않습니다.

860px 이하에서는 긴 수치·비교 표·주제 선택을 화면 폭 안에서 아래로 흘립니다. 지역 선택은 900px 이하부터 권역별로 줄바꿈합니다. 가로 넘침을 페이지 전체에서 숨겨 내용을 자르지 않고, 각 그리드의 최소 너비와 값의 줄바꿈을 조정합니다. 기기의 움직임 줄이기 설정에서는 로딩 표시자도 회전하지 않습니다.

## 관리자 화면의 공통 기준

`/admin/`도 같은 토큰과 `kj-btn`·`kj-badge`를 사용합니다. 검은 제호와 괘선으로 실시간·기간별 통계·발행 현황을 구분하고, 활성 사용자만 큰 청색 숫자로 강조합니다. 760px 이하에서는 그래프와 두 열 목록을 아래로 흘립니다. 표는 선택 기능이 없는 읽기 전용 두 열이며 긴 페이지 제목을 줄바꿈합니다.

| 기능 | 기준 소유자 | 동작과 검증 |
| --- | --- | --- |
| 기간 선택 | `admin/index.html`의 기본 `select` | 기기 기본 팝업·키보드를 사용하고 변경 즉시 이전 기간 수치를 비움 |
| OAuth ID 입력 | `admin/app.js`의 설정 폼 | 명시적 제출, 인라인 오류·`aria-invalid`, 첫 오류 필드에 포커스 |
| 인증·요청 안내 | `admin/app.js`의 상태 영역 | 연결 전·중·완료·거절·만료·장애 구분, 마지막 조회 시각 유지 |
| 새로고침 | `admin/app.js`의 단일 요청 주기 | 중복 실행 방지, 숨긴 탭 중지, 12초 제한, 늦은 응답 차단 |
| 스크롤 | 공통 문서 흐름과 `admin/admin.css` | 루트 너비를 숨기지 않고 320~1440px에서 가로 넘침 검사 |

연결 전에는 통계를 숨기고 인증 정보 입력 안내와 공개 발행 현황만 보여 줍니다. 0건을 오류로 표현하지 않으며, 실패한 수치를 0으로 채우지 않습니다. 실시간은 최근 30분, 기간별 수치는 속성 시간대 기준임을 표시합니다. 인증 만료·권한 오류·연결 해제 시 통계 내용을 제거합니다. 동작 검증 소유자는 `dev/tests/browser/admin.cjs`입니다. 실제 OAuth 설정과 API 연결 확인은 [관리자 연결 문서](../docs/dev/ga4-admin.md)에 구분해 기록합니다.

## 뉴스 리디자인 · 2026-10-30

[Figma 원본](https://www.figma.com/design/Eep2qLjiPT9jhDUyLU8Zjx)의 흰 지면, 명조 제호·머리기사, 파란 강조선과 본문 중심 배치를 반영했다. 공용 관리자 스타일은 유지하고 공개 지면에 `editorial.css`를 적용한다. 데스크톱 본문 폭은 1120px, 모바일은 한 열로 자연스럽게 이어진다. 경제 지표 네 개는 실제 발행 데이터에서 가져온다.

추적 막대는 분야 메뉴 아래 고정되며 세션 동안 숨길 수 있다. `추적 2`로 패널을 다시 열고, Esc·닫기·배경 클릭으로 닫는다. 상세 기사와 타임라인은 패널의 펼침 항목과 2면 이슈 추적에서 확인한다. 지난 호에는 현재 추적 기록을 표시하지 않는다.

진행 막대는 편집상 단계이며 해결률이 아니다. 무안공항 참사는 최종 발표일이 미확정이므로 기간 백분율을 표시하지 않는다. 조사 결과·수색 종료·송치 후 처분·안전 권고 이행은 각각 근거가 생겼을 때 갱신한다. 자동 발행 여부와 사람 확인 표시는 기존 정책을 따른다.


### 지면 순서와 도구 상태 개선

1면은 오늘의 전국 뉴스, 2면은 이슈 추적이다. 이후 주요 뉴스·지역·언론·정치·경제·산업·재정의 상대 순서는 유지한다. 모바일 제호는 로고·메뉴, 날짜·발행 상태, 공유·글자 크기의 세 줄로 나눠 발행 배지가 도구 영역과 겹치지 않게 한다. 도구 이름은 모바일에서도 표시한다. 선택된 글자 크기 버튼은 `brand` 배경과 `on-brand` 글자를 함께 사용하며 다크 모드에서도 대비를 유지한다.

PC와 모바일 모두 한 화면 이상 스크롤하면 맨 위로 버튼이 표시된다. 기간 경과 패널은 브랜드색 상단 선과 옅은 배경, 데스크톱 24px·모바일 20px 안쪽 여백으로 구분한다. 공통 진행 패널의 미정의 `space-5` 참조를 기존 `space-6` 토큰으로 수정한다.
