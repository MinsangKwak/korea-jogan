# 현재 지면과 공통 UI 기준

**PC는 정보를 나란히 비교하고, 모바일은 핵심 정보를 먼저 읽도록 구성합니다.** 요약·진행 단계·대표 숫자·기준일·검색을 항상 표시하고, 보조 내용은 화면 폭과 길이에 따라 펼칩니다.

2026.11.05 운영 지면 기준입니다. 지면·브랜드 개편은 11/04 운영 반영됐습니다. [서비스](https://korea-jogan.com/) · [변경 기록](../docs/dev/changelog.md) · [문서 안내](../docs/README.md)

## 현재 지면의 순서와 배치

읽는 순서는 **전국 → 이슈 추적 → 홈(주요 뉴스) → 지역 → 언론 → 정치 → 경제 → 산업 → 재정**입니다. 1면 전국 뉴스와 2면 이슈 추적을 먼저 배치합니다. 지면의 기준은 [reading.css](../dev/web/src/styles/reading.css)와 각 컴포넌트입니다.

최대 바깥 너비는 1,360px입니다. 좌우 여백은 화면 폭에 따라 16~44px이며 기기 안전 영역이 더 크면 그 값을 사용합니다. 기사 안쪽 여백은 20~28px입니다. 짧은 기사의 배경을 같은 행의 긴 기사 높이만큼 늘리지 않고 위쪽을 정렬합니다.

| 영역 | 넓은 화면 | 좁은 화면 |
| --- | --- | --- |
| 이슈 추적 | 1,100px 이상에서 사안 카드 자체를 2열로 배치 | 사안별 한 열 |
| 주요 뉴스 | 901px 이상에서 머리기사 왼쪽·보조 주제와 숫자 오른쪽 | 머리기사 다음에 보조 내용의 펼침 제목 표시 |
| 언론 | 1,100px 이상에서 제목·설명 왼쪽·검색창 오른쪽 | 설명 아래 전체 폭 검색창 |
| 산업 | 1,100px 이상에서 요약·지표·출처 왼쪽·품목 그래프 오른쪽(1:1.2). 주력산업은 대표 수치로 비교 | 요약·지표 다음에 그래프의 펼침 제목 표시. 주력산업 상세는 목록 아래 표시 |
| 전국 뉴스 | 1,000px 이상에서 본문과 기사 제목 목록을 1.65:1로 배치 | 본문 다음에 제목 목록 |
| 정치 | 1,040px 이상에서 임기·D-Day 왼쪽, 이번 주 일정 오른쪽 | 임기 → D-Day → 일정 순서 |
| 재정 | 1,040px 이상에서 국가채무 그래프 왼쪽, 예산·연금 오른쪽 | 국가채무 → 예산·연금 순서 |
| 경제 | 1,100px 이상 3개·1,350px 이상 4개를 보는 순환 목록 | 700~1,099px는 2개, 700px 미만은 한 카드 중심 |
| 푸터 | 수집 한계/출처, 지난 호/정정을 각각 2열로 구분 | 1,024px 이하 한 열 |

전국 뉴스는 본문 한 편과 제목 목록으로 나눕니다. 기본 제목 5건을 보여 주고 나머지는 더보기로 엽니다. 제목을 선택하면 본문을 바꾸고 새 제목으로 키보드 포커스를 이동합니다.

## 핵심 정보와 부가 내용의 펼침

일반 기사 목록은 앞의 3건을 먼저 보여 주고 나머지는 더보기로 엽니다. 아래 부가 내용은 네이티브 `details`·`summary`로 제공하며 PC에서도 독자가 닫을 수 있습니다.

| 부가 내용 | 대상 | 901px 이상 기본 상태 | 900px 이하 기본 상태 |
| --- | --- | --- | --- |
| 오늘의 흐름 | `#natFlow` | 펼침 | 접음 |
| 함께 읽을 주제·핵심 숫자 | `.lead-extras` | 펼침 | 접음 |
| 이슈 진행 일정 | `.kj-track__timeline` | 펼침 | 접음 |
| 산업 품목별 그래프 | `#industryChart` | 펼침 | 접음 |
| 이슈 근거 기사·확인 기록 | `.kj-track__sources` | 3건 이하는 펼침, 그보다 길면 접음 | 접음 |

[responsiveDisclosure](../dev/web/src/core/ui.js)는 같은 페이지에서 넓은 화면·좁은 화면의 사용자 선택을 각각 기억합니다. 폭을 바꿨다가 돌아오면 그 화면에서 고른 상태를 유지하고, 같은 요소에 이벤트를 중복 연결하지 않습니다. 페이지를 새로 열면 기본 상태를 적용합니다.

접힌 항목도 제목과 일정·기사 건수를 표시합니다. 이슈의 요약·현재 단계·다음 확인·주의사항, 경제 지표의 값·변동·원문 기준일, 언론 검색창은 항상 남깁니다. 경제 기준일은 `.econ-base`로 따로 표시합니다. 전체 메뉴에서 접힌 보조 숫자로 바로 이동하면 먼저 해당 영역을 펼칩니다.

## 높이와 스크롤

PC에서 나란히 읽는 두 열은 짧은 쪽의 실제 높이에 맞추고, 긴 쪽에서만 스크롤할 수 있습니다. 내용이나 글자 크기가 바뀌면 높이를 다시 맞춥니다.

| 영역 | 높이 기준과 동작 |
| --- | --- |
| 전국·주요 뉴스·정치·재정·산업 | 위 표의 두 열 기준과 창 높이 600px 이상에서 짧은 열에 맞춤. 전국 기사 한 건이나 주요 뉴스·산업의 보조 영역을 접은 경우에는 자연 높이 사용 |
| 이슈 추적 | 폭 1,100px·창 높이 600px 이상에서 사안 두 건을 나란히 놓으면 짧은 카드 높이에 맞춤. 그 외 카드가 나란히 놓일 때는 본문을 최대 `min(72dvh, 42rem)` 안에서 읽음 |
| 전체 메뉴 | 패널은 `100dvh` 안에 두고 닫기 헤더를 유지하며 본문만 스크롤 |
| 추적 모달 | 화면 높이 안에서 스크롤하며 닫기 헤더 유지. 상세를 열면 반복 요약·단계를 제외한 일정과 근거 표시 |
| 푸터 | 별도 높이 제한 없이 문서 흐름으로 연결 |

모바일과 높이가 낮은 창에서는 열 높이를 제한하지 않습니다. [높이 맞춤](../dev/web/src/core/paired-reading.js)은 두 열의 원래 콘텐츠 크기를 관찰하며, 넘치는 열에만 이름과 키보드 포커스를 제공합니다. 지역 선택과 검색, 푸터는 문서 흐름을 따릅니다.

## 경제 지표 순환

[경제 컴포넌트](../dev/web/src/components/economy/economy.js)는 로컬 Swiper 14.4.0을 경제 섹션 800px 전에서 비동기로 불러옵니다. 첫 지면 준비를 기다리게 하지 않습니다. 표시 수는 실제 자료 개수 안에서 조정하며, 작은 화면도 폭이 허용되면 다음 카드 일부를 표시합니다. 지표가 충분하면 무한 순환하고, 적으면 rewind 또는 이동 잠금을 사용합니다. [원본·라이선스·해시](../dev/web/assets/vendor/swiper/README.md)를 함께 보관합니다.

이전·다음, 현재 위치, 자동 넘김 켜기·끄기를 제공합니다. 목록에 포커스가 있을 때 좌우 방향키로도 이동합니다. 자동 넘김 간격은 8초이며 읽는 동작에 맞춰 제어합니다.

| 상황 | 자동 넘김 |
| --- | --- |
| 마우스 호버·목록 안 포커스·영역이 화면 밖·숨긴 탭 | 해당 조건 동안 정지 |
| 직접 이동·모바일 터치·출처 또는 집계 설명 열기 | 사용자가 다시 켜기 전까지 정지 |
| 기기의 동작 줄이기 설정 | 기본 해제, 전환 동작 축소 |

화면 밖 슬라이드의 버튼은 키보드 탐색에서 제외합니다. 목록은 지표명·값·변동·기준일을 같은 순서로 표시합니다. 집계 설명과 출처는 처음에는 접혀 있고, 지표를 선택하면 목록 아래에 한 건만 펼칩니다. 라이브러리 로드·초기화에 실패하거나 늦게 준비되어 읽던 위치를 바꾸게 되는 경우 모든 지표를 격자로 표시하고 상세 읽기는 계속 제공합니다.

주력산업 목록도 같은 흐름으로 읽습니다. 분야별 대표 수치에 실제 지표명을 붙이고, 넓은 화면에서는 다섯 분야를 한 줄에 놓습니다. 좁은 화면에서는 읽기 좋은 너비를 확보하도록 두세 열 또는 한 열로 배치합니다. 상세를 선택하면 분야 요약·전체 지표·출처·관련 기사를 목록 아래에 한 번에 보여 줍니다. 경제와 주력산업의 상세 영역은 문서와 함께 스크롤합니다.

## 탐색과 읽기 도구

[SECTIONS](../dev/web/src/core/config.js)를 탐색의 공통 기준으로 사용합니다. 상단 분야 메뉴는 현재 위치를 표시하고, 전체 메뉴는 주제·분야·시도까지 연결합니다. 900px 이하에서는 상단 메뉴를 축약하며 지역 선택은 권역별로 줄바꿈합니다. 하단 탐색은 문서 흐름에 두고 오른쪽 세로 메뉴는 공개 지면에서 숨깁니다.

PC·모바일 모두 한 화면 이상 내려가면 맨 위로 버튼을 표시합니다. 이동 후에는 제호로 포커스를 돌립니다. 전체 메뉴·추적 모달은 Esc와 닫기 버튼을 제공하고 연 버튼으로 포커스를 되돌립니다. 추적 막대를 숨기면 분야 메뉴에 다시 열기 버튼이 나타납니다. 지난 호와 주제별 기록 링크는 전국 기사 목록 다음에 표시합니다.

글자 크게와 어두운 화면은 같은 스위치로 제어합니다. 손잡이 위치와 `켬`·`끔` 글자, `aria-checked`로 상태를 전달합니다. 제호·전체 메뉴·지난 호 목록과 이슈·지표 페이지의 선택은 같은 기기에서 이어집니다. 기기 설정과 관계없이 처음에는 밝은 화면으로 열립니다. 어두운 화면을 선택하면 저장하고, 스위치를 끄면 밝은 화면으로 돌아갑니다.

## 문구와 숫자의 표현

결론을 첫 문장에 쓰고 수치·근거·배경을 이어 설명합니다. [readingText](../dev/web/src/core/ui.js)는 긴 요약의 첫 문장과 나머지를 시각적으로 나누면서 문자열의 순서·내용을 보존합니다. 가독성을 이유로 제목·본문의 한정어나 수사 상태를 지우지 않습니다. 작성 원칙은 [발행 런북](../docs/planning/editorial.md#글을-읽을-이유를-첫-문장에-두기)을 따릅니다.

상승·하락은 기호와 글자로 전달하고 오류색 `danger`를 하락에 사용하지 않습니다. 출처는 A~E 문자로, 결산·전망은 배지와 선 형태로 구분합니다. 미확인 값을 추정해 채우지 않고, '약'은 원자료가 제공한 정밀도에 맞춰 사용합니다.

추적의 단계는 보도에 따른 편집상 정리이며 공식 해결률이 아닙니다. 최종 발표일이 미확정인 사안은 기간 백분율을 표시하지 않습니다. 경과 기간과 확인된 단계, 예정과 완료를 구분합니다. 산업의 핵심 지표와 품목 그래프도 각각의 기준월을 유지합니다. 자동 발행 표시는 사람의 원문 대조 표시와 구분합니다.

## 시각 기준과 토큰

신문의 제호·머리기사·괘선으로 정보 위계를 드러냅니다. ‘조간’은 하루 한 호를 읽는 사용 상황, ‘대한민국’은 전국·17개 시도와 정치·경제·산업·재정의 범위입니다. 디자인이 신뢰나 이용률을 높였다는 효과는 별도의 사용자 검증 결과 없이 주장하지 않습니다.

제호·머리기사는 Noto Serif KR, 본문은 Noto Sans KR을 사용하고 기기 기본 한글 글꼴을 대체 글꼴로 둡니다. 본문 400, 강조 500·700, 제목·대표 숫자 900 굵기와 숫자의 `tabular-nums`를 사용합니다. 기준 글자는 18px, 900px 이상 19px, 큰 글자는 23px입니다. 설명 문단의 공통 최대 너비는 `42rem`입니다. 보조 표기의 토큰 최솟값은 `caption` 0.8rem이며 최신 숫자 띠·지역 선택·토글 상태에는 더 작은 예외가 있습니다.

밝은 테마는 푸른 기가 도는 밝은 지면과 짙은 잉크색, 어두운 테마는 배경 `#181818`과 상위 면 `#252526`을 사용합니다. 기사 면·도구·모달은 `surface-raised`로 구분합니다. 기본 화면 모드는 라이트이며 다크를 켰을 때만 `jogan-theme`에 저장합니다. 제호·전체 메뉴·목록 페이지와 관리자 화면이 저장한 색상 선택을 적용하고, 저장소가 막혀도 현재 페이지 전환은 동작합니다. 작은 초기 코드가 CSS 전에 모드만 적용하고 비동기 `core/theme.js`가 조작·저장을 연결합니다.

색·글자·간격 원본은 [tokens.json](tokens.json)입니다. 생성 CSS를 직접 편집하지 않고 아래 명령으로 갱신합니다.

```bash
python3 dev/pipeline/build/build_tokens.py
python3 dev/pipeline/build/build_tokens.py --check
```

| 색 토큰 | 역할 |
| --- | --- |
| `bg`, `surface`, `surface-raised` | 본문·구분 영역·상위 패널 |
| `ink`, `ink-2`, `ink-3` | 제목·본문·보조 정보 |
| `line`, `line-strong` | 구분선·조작 경계 |
| `brand`, `brand-strong`, `brand-soft`, `on-brand` | 주요 행동·선택·강조와 그 위 글자 |
| `hl`, `hl-soft` | 전통 산업·안내 |
| `head`, `head-ink`, `head-line` | 제호와 그 안의 글자·경계 |
| `danger`, `danger-soft` | 불러오기 실패 등 오류 |
| `bar`, `chart-1`~`chart-6` | 그래프 계열과 문자 범례 |
| `focus`, `scrim` | 포커스·서랍 가림막 |

밝은 테마의 주요 청색은 `#24577c`, 산업 강조는 `#a14a00`입니다. 어두운 테마 값은 토큰 원본에 따로 정의하며 화면 모드 스위치로 적용합니다.

| 글자 토큰 | 크기 | 용도 |
| --- | --- | --- |
| `display-1`, `display-2` | 최대 2.6rem, 1.9rem | 머리기사·섹션 제목 |
| `title-lg`, `title`, `title-sm` | 1.5rem, 1.25rem, 1.05rem | 제호·패널·기사 제목 |
| `num-xl`, `num-lg`, `num-md` | 2.2rem, 1.8rem, 1.3rem | 대표 숫자·D-Day |
| `lead`, `body`, `body-sm` | 1.1rem, 1rem, 0.92rem | 요약·본문·표 |
| `label`, `meta`, `caption` | 0.9rem, 0.85rem, 0.8rem | 메뉴·출처·범례 |

간격은 `space-1`~`space-10`을 사용합니다. 공통 카드 안은 `space-4`, 섹션 위아래는 `space-10`이 기준이며 공개 지면의 별도 값은 앞의 지면 규칙을 따릅니다. 공통 모서리는 막대 2px·배지 4px·카드 8px·버튼/칩 pill이며 기사에는 상단 괘선과 작은 모서리만 두고, 여백과 글자 위계로 본문·요약·출처를 구분합니다. 선은 1px 구분선, 3px 괘선·포커스를 기준으로 합니다. 그림자는 고정 메뉴·서랍 등 떠 있는 요소에 사용합니다.

## 공통 컴포넌트와 상태

| 역할 | 클래스·함수 | 유지할 동작 |
| --- | --- | --- |
| 제목·숫자 | `kj-sec`, `kj-sechead`, `kj-label`, `kj-stat`, `kj-num`, `kj-dir` | 분류·값·기준과 방향 구분 |
| 출처·배지 | `kj-src`, `kj-grade--a`~`--e`, `kj-badge` | 기관·원문, 결산·전망 상태 |
| 그래프 | `kj-bars`, `kj-bar--forecast`, `kj-bar--unknown` | 전망·미확인 구별 |
| 목록·펼침 | `collapse`, `kj-more`, `responsiveDisclosure` | 더보기 건수와 펼침 선택 |
| 조작·탐색 | `kj-btn`, `kj-chip`, `kj-cats`, `kj-tabbar`, `kj-drawer` | 같은 섹션 정보와 상태·포커스 |
| 안내·비동기 | `kj-notice`, `kj-status`, `kj-skel`, `kj-state` | 발행 상태·로딩·오류·재시도 |

첫 접속은 텍스트와 표시자로 읽기 준비를 알립니다. 데이터 요청은 최대 12초 뒤 중단하며, 스크립트가 실행되지 않으면 20초 후 재시도와 미리 만든 호 요약을 제공합니다. 정정·최신 숫자 요청은 본문 준비를 지연시키지 않습니다. 860px 이하의 긴 수치·비교 표·주제 선택은 아래로 흐르게 하며 페이지 전체를 숨겨 가로 넘침을 덮지 않습니다.

접근성 확인 목표는 본문 대비 4.5:1·주요 비문자 요소 3:1·조작 영역 44px 이상입니다. 색 외에 문자·기호·형태를 쓰고 키보드 포커스와 `aria-current`·버튼의 `aria-expanded`·기본 `details` 동작을 유지합니다. 동작 줄이기 설정에서는 스크롤·서랍·로딩 애니메이션을 줄이거나 끕니다. 이는 인증이나 전체 화면의 적합성 판정이 아니며 밝기·큰 글자·오류·키보드를 함께 확인해야 합니다.

## 관리자·삽화와 관련 문서

관리자도 같은 토큰과 버튼·배지를 사용합니다. 연결 전에는 비공개 통계를 숨기고 공개 발행 현황과 설정 안내만 표시합니다. 0건과 조회 실패를 구분하고, 인증 만료·권한 오류·연결 해제 시 수치를 제거합니다. 760px 이하에서 그래프·목록을 아래로 흘리고 긴 표 제목을 줄바꿈합니다. 실제 계정 연결 조건과 검증 범위는 [관리자 문서](../docs/dev/ga4-admin.md)를 따릅니다.

제호 아래 삽화는 제거하고 바로 뉴스 탐색과 본문으로 이어지도록 했습니다. 제호·파비콘·앱 아이콘에는 `ㅈ` 심벌을, 공유 미리보기에는 ‘첫 빛’ 이미지 `og-first-light.png`를 사용합니다. 홈·지난 호·구조화 데이터가 같은 이미지를 참조하며, 이전 픽셀 삽화는 자산 이력으로 보존합니다. [브랜드 자산·이전 삽화·재생성](illustrations.md)을 별도로 관리합니다.
