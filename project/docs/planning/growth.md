# 독자 유입과 측정 계획

**첫 4주의 목표는 외부 방문자 100명입니다.** 정치 뉴스가 낯선 독자가 검색이나 공유 링크로 들어와 질문의 답을 읽고 근거 원문까지 확인하는 과정을 살펴봅니다. [정치 질문 모음](https://korea-jogan.com/politics/) · [서비스 기획](01-product.md)

## 정치 질문 지면의 첫 4주

세 가지 질문을 관찰합니다. 학자금대출 질문은 적용 대상과 시행일을, 재판 기일은 다음 일정과 확인일을, 파기환송은 용어의 뜻과 실제 판결 주문을 한 페이지에서 확인할 수 있습니다. [학자금대출 이자 면제](https://korea-jogan.com/politics/regional-student-loan-interest/) · [재판 기일](https://korea-jogan.com/topics/lee-jae-myung-trials/) · [파기환송 해설](https://korea-jogan.com/politics/reversal-and-remand/)

| 확인할 질문 | 측정 방법 | 결과에 따른 결정 |
| --- | --- | --- |
| 외부에서 몇 명이 들어왔는가? | GA4에서 내부·자동화 방문으로 식별된 접속을 제외하고 28일간 사이트 전체 활성 사용자 수를 확인 | 검색과 소개 글에서 각각 몇 명이 들어왔는지 확인하되, 채널을 중복 이용한 독자가 있으므로 목표 달성 여부는 사이트 전체값으로 판단 |
| 어떤 질문이 검색 결과에 보이는가? | Search Console에서 서비스명을 제외한 검색어의 노출·클릭을 질문별로 확인 | 노출이 없으면 색인을 점검하고, 노출만 있으면 실제 검색어와 페이지 제목·첫 답을 대조 |
| 답을 읽고 무엇을 더 여는가? | GA4에서 근거 원문·용어·캘린더를 연 횟수를 질문별로 확인 | 반복해서 열리는 주제는 다음 질문 후보에 넣고, 원문 열람이 드물면 링크 위치와 안내 문구를 점검 |

첫 2주에는 주제 두 개를 관련 외부 채널 두 곳에 소개할 계획입니다. 4주째에는 질문별 방문과 후속 행동 건수를 살피고, 표본이 작으면 관찰 기간을 늘립니다. 한 사람이 원문을 여러 번 열 수 있으므로 클릭 횟수와 방문자 수를 따로 기록합니다. [관리자 지표 정의](../dev/ga4-admin.md)

## 검색 노출과 색인 점검

홈의 제목은 ‘광고 없는 오늘의 뉴스 요약 | 대한민국 조간’으로 고정합니다. 설명에는 국내 주요 뉴스 요약과 같은 이슈의 언론사별 보도·원문 비교를 안내합니다. 날짜별 조간은 해당 호의 머리기사와 발행일을 제목에 담습니다.

정치 질문, 이슈, 지표, 지역 기사, 매체별 수치 비교에는 각각 고정 주소가 있습니다. 검색으로 처음 들어와도 제목·본문·출처를 읽을 수 있게 정적 HTML로 발행하고 대표 주소(canonical)를 사이트맵에 수록합니다.

관리자의 ‘Google 검색 연결’에서는 상위 검색어·페이지 각 10개, 세 질문의 실적, 대표 주소의 색인 상태를 조회합니다. 확정 자료는 태평양 시간 기준 3일 전까지이며 조회 기간은 7일 또는 28일입니다. [Search Console 연결 설정](../dev/ga4-admin.md#google-검색-연결)

1. 검색 유형을 **웹**으로 두고, 같은 기간·기기에 대해 전체 국가와 대한민국을 각각 확인합니다. 검색어는 익명 처리될 수 있어 검색어별 노출 합계가 전체값과 다를 수 있습니다.
2. 노출과 클릭이 함께 줄면 색인 제외 사유와 Google이 선택한 대표 주소를 확인합니다. 노출이 비슷하면 검색어가 묻는 내용과 제목·첫 답이 맞는지 읽어봅니다.
3. 검색 클릭과 GA4 유입 추이가 다르면 기간·호스트·내부 접속 제외·태그 차단 여부를 점검합니다. 홈 실적은 경로 `/`로, 날짜별 조간은 각 호의 고정 주소로 확인합니다.

## 외부 소개

관리자의 ‘홍보 글과 추적 링크 만들기’에서 제목·핵심 세 줄·질문의 고정 주소를 복사합니다. 학자금 정책은 대학·취업 커뮤니티의 정보공유 게시판처럼 질문과 독자가 맞는 곳을 고릅니다. 소개 글에는 답을 먼저 싣고 적용 조건과 출처를 확인할 수 있는 링크를 덧붙입니다.

게시 뒤에는 게시일·게시 URL·도착 URL을 기록합니다. 외부 소개 링크에는 게시처(`utm_source`), 전달 경로(`utm_medium`), 캠페인(`utm_campaign`)을 붙입니다. 같은 질문을 다른 문구로 소개할 때는 `utm_content`로 구별합니다. 신문 내부 메뉴에는 질문의 고정 주소를 그대로 사용합니다.

## 재방문과 새 호 알림

1면의 ‘최근 달라진 이슈’는 브라우저가 마지막으로 홈을 본 날짜와 사건 변경일을 비교해 새 소식을 표시합니다. 독자는 홈·지난 호·기록 페이지에서 RSS 주소를 확인하거나 복사할 수 있습니다. 관리자는 안내 열기, 주소 복사, RSS 링크 클릭을 각각 집계합니다. 실제 구독자 수는 이 집계에서 알 수 없습니다. [RSS 피드](https://korea-jogan.com/feed.xml)

발행 시 최근 이틀간 공개한 호를 `news-sitemap.xml`에 수록하고 WebSub 허브에 RSS 갱신을 알립니다. 독자에게 공개된 호의 색인 여부는 Search Console에서 확인합니다.
